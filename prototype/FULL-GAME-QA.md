2026-10-05。実装、ローカルの実ブラウザ、生成音声のファイル、Pages用の静的成果物を確認。スマートフォン実機、Cloudflare実配信、全編の人による聴取は未確認。

## 実ブラウザで確認できた範囲

- 旧赤箱体験版のセーブから、赤だけ開いた状態を引き継いだ。六文字や救出完了を誤って付与しない。
- 三箱の画面から青・黄の箱へタップで進める。
- 青箱の四段階の調査、要求した場合のサガルマータ情報、原作時点の高さの注意書き。
- 数字の空入力・8849の誤答で開封しない。全角８８４８で開封。正解ボタンのダブルクリックでも紙が重複しない。
- 入力途中に再読み込みし、「続きから遊ぶ」で全角数字・調査段階が復元される。読み込み直後に音声は自動再生しない。
- WAV音声とLaid_BackのMP3が別々に再生され、停止ボタンで両方が止まる。
- 390×844のブラウザ幅で黄色の箱・手がかり・ダイヤルを確認。絵を小さく調整し、操作を台詞全文より前に置いた。
- 黄箱の四段階の手がかり、0000の誤答反応、ダイヤルだけで2502に合わせて開封。
- 六文字を取得。合言葉の空入力・「だいすき」で進まない。「 ダイスキ ダヨ 」でまほう使いが登場。
- 「いったん、しおりをはさむ」の分岐でサンタがまだ閉じ込められている原作台詞と再呼び出し操作を表示。

ここでブラウザ操作がセキュリティポリシーに拒否されたため、終盤の実画面操作を中断した。別のブラウザや別方式で迂回していない。以下は状態遷移・ファイル・HTTP検査であり、終盤を実ブラウザで通したという意味ではない。

## 自動検査

`npm test`：20件成功。主な対象は全六通りの箱順、紙の重複防止、数字と自由回答の表記揺れ、空入力、古いイベントの拒否、再開・破損セーブ・履歴の検査、早い合言葉、保留と再呼び出し、三問すべて不正解でも救出する原作条件、完了と読み返し、旧セーブの移行、声とBGMの停止・ミュート、全収録場面のWAVハッシュ。

ローカルでは原作コピーとの直接照合二件も成功。公開クローンでは原本がないため、その二件だけを明示してスキップする。

`npm run check:design`：原作問題群を対象にした設計モデル2,592経路。現在の固定出題の全編画面2,592回を操作したという意味ではない。設計モデルの元の別名候補は原本との照合のため保持し、実装では承認された誤判定修正を適用。

`npm run build`：12の実行ファイル、40の音声ファイルを `dist/` に出力。原本・APIキー・制作スクリプト・生成記録はPagesへ出力しない。`npm run check:pages` はその成果物をローカルHTTPで配信し、ファイル一致、CSP、音声Range配信、非公開パスの404を検査する。

## 音声

追加29点はユーザーがGoogle Gemini APIへの原作台詞送信・生成を承認した範囲で各一回生成。音声再生成の自動再試行は行っていない。新しい契約や課金設定を変更していない。

全38WAVは24kHz・16bit・モノラル、無音ではなく、クリップしたPCMサンプルは0。各ファイルのSHA-256を生成記録と照合した。これは誤読・読み落としがないことの証明ではない。全編の聴取は未完了。

公開標準単価による参考額は追加分約0.15321米ドル、既存分を含めて約0.20787米ドル。実請求・無料枠は未確認。測定値は `reference/audio-generation/wave-check.json`。遊ぶ際に生成APIは呼ばない。任意の数字の誤答やファイル再生失敗時のブラウザ読み上げは、端末によって声・品質が異なる。
