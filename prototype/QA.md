# 動作確認記録

確認日: 2026-10-04（日本時間）。公開・デプロイなし。サブエージェント不使用。

## 起動と環境

- Node.js v24.18.0 / npm 11.16.0。
- `npm start` で開発用静的配信を起動し、実際のCodex内蔵ブラウザで `http://127.0.0.1:4173/` を開いて操作した。
- スマートフォン幅390×844、320×740、タブレット幅768×1024、PC幅1280×900で表示を確認。ブラウザのビューポート変更による確認であり、実機端末の検証ではない。
- 保存先は同一ブラウザのlocalStorage。外部通信、アカウント、ゲーム用バックエンド、DB、アクセス解析、課金、音声認識は追加していない。

## 実際のブラウザで確認した項目

| 確認 | 結果 |
| --- | --- |
| 開始方法 | 「サンタを助ける」が表示され、タップ・Enterで導入が始まる。320px幅の最初の表示でも開始ボタンが画面内に入るよう調整 |
| 原作導入 | 端末からの声、サンタの救難通信、プレゼントの準備が間に合わない理由が表示される |
| 調べ方 | 赤い箱に「タップして調べる」、調査ごとに明示的な次のボタンが出る |
| 未実装 | 青・黄は「今回は対象外」で無効化。原作の自由順を説明し、続きを操作できるように見せない |
| 空入力 | 「四つの数字を入力してください」。箱は閉じたまま、入力欄へフォーカス |
| 不正形式 | `31a8` は「0〜9の数字を四つ入力してください」。開箱しない |
| 不正解 | `0000` は原作の不正解反応を表示し、同じ箱で再試行できる。責める言葉なし |
| 正解 | 全角・空白を含む正解で開箱。入力は正規化され、原作どおり「す」「だ」を得る |
| 原作の判定条件 | PCで調査1から正解をEnter送信して開箱。全手がかりの表示を必須条件にしない |
| 連打 | 箱の選択、調査、正解・不正解の送信、聞き直しをダブルクリックして状態が壊れない。調査1→2の連打で調査3を勝手に出さない |
| ヒント | 要求前は絵の下のバツを出さない。「絵の下を調べる（原作のヒント）」で原作の第4段階を出す。追加ヒントなし |
| 聞き直し・停止 | 聞き直しで「読み上げ中」、停止で「音声を停止しました」。表示・進行は保持 |
| ミュート | 進めても「音声オフ・文字で遊べます」。音声オフのまま開箱まで操作できた。解除後の聞き直しも動作 |
| 台詞表示 | 台詞を閉じる／文字で読む、双方がクリック・Enterで動作 |
| 途中再開 | 調査3・入力途中の `３１` ・ミュートを保存。リロード後「続きから遊ぶ」で同じ状態へ戻る |
| 開箱後の再開 | リロード後も開箱済みと試作終了を復元 |
| リセットのキャンセル | 確認画面から「続きに戻る」で開箱済みを保持 |
| リセットの実行 | 初期状態へ戻り、再読み込み後も開始前。入力・調査は消え、音声設定は保持 |
| 終了 | 「体験プロトタイプはここまで」を表示。サンタの救出完了とは表示しない |
| 思考時間 | ゲームの状態にタイムアウトの処理なし。途中の検証中も自動で進行・失敗しない。読み上げの終了は進行条件にしない |
| レイアウト | 320px幅で見つかった横幅と音声ボタンの折り返しを修正。画面下へスクロールしても音声操作が見える |
| 開発者ログ | PCでの開箱までの操作後、警告・エラーログは0件 |

台詞が聞こえたか、声が親しみやすいかという音響・主観品質は、ブラウザの表示状態だけでは確認できない。今回確認したのは読み上げAPIへの再生・停止指示、状態表示、音声オフでも完走できる操作である。

## 自動テスト

`npm test`（Node標準テストランナー、子プロセス分離なし）: **7件成功**。

1. 原作の実際の出題候補・正解対応・赤い箱の台詞を参照コードと照合。
2. 全角・空白、空入力、長さ、文字混入を判定。
3. 正解だけで開箱し、空・不正解・未開始・二重回答で開箱しない。
4. 調査回数の上限、入力・ミュートの復元、リセット。
5. 壊れたセーブ、不整合な開箱データ、保存拒否の扱い。
6. 音声を一桁ずつ読む、再生の置換、ミュート、古い終了イベントの無効化（音声APIの代替オブジェクトで検証）。
7. 音声未対応・再生エラー時の文字案内（音声APIの代替オブジェクトで検証）。

`app.js` / `serve.mjs` はNodeの構文チェックも通過。依存ライブラリのインストールは不要。

## 今回の確認の限界

- iPhone Safari / Android Chromeの実機、端末のスピーカー・ヘッドホン、実際の日本語音声の品質・読み方は未検証。
- タブ非表示で音声を止める処理は実装。OSによるバックグラウンド・ロック画面・電話等の中断は実機未検証。
- 初見ユーザーを参加させたプレイテストはしていない。「説明なしで全員が遊べる」「面白さを検証済み」とは判断しない。
- 原作の音楽・効果音は利用条件未確認のため不使用。ブラウザ読み上げの声・品質は端末差がある。
- タブレットは表示と再開・リセット、スマートフォン幅とPC幅は開箱までの操作を確認した。
