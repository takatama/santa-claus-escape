# Santa Claus Escape / サンタの脱出

原作の日本語版の導入から、赤色の箱が開くまで遊べる、声と仕掛けの絵本。2026-10-05に絵本版へ更新。

紙のミニチュアをSVGとCSS 3Dで組み立て、ページを進めると木とサンタの端末が立ち上がる。正解で箱のふたが開き、原作の「す」「だ」の紙が現れる。スマホは一ページ、横向きタブレット・PCなど801px以上の画面は見開き。画像生成サービスや外部ライブラリは使用していない。

## 起動

このフォルダで実行:

```powershell
npm start
```

ブラウザで `http://127.0.0.1:4173` を開く。Node.js 24以降で起動し、npm installは不要。開発用のローカル静的配信のみで、ゲームのバックエンドはない。GitHubでのソース公開に対応し、プレイ用サイトのデプロイは行っていない。

## 操作

1. 「サンタを助ける」で開始。サンタの通信を聞く／読む。
2. 「はい、箱を調べる」→赤色の箱をタップ。
3. 書き込み、絵、絵の下をタップで調べる。
4. 四桁を入力して「数字を合わせる」。空白・全角数字も受け入れる。
5. 正解で「す」「だ」の紙を見つけ、試作終了。「最初から謎を解く」でリセットできる。
6. 「この絵本を読み返す」で七場面を前後に読む。再回答は不要で、クリアした進行は保持する。読み返し中に再読み込みした場合は、クリア画面から再開する。

聞き直し、停止、音声オン／オフ、台詞表示切替を用意。進行と入力途中の答えを端末内に自動保存し、再読み込み後は「続きから遊ぶ」で再開できる。保存を禁止されたブラウザでも、現在のページでは遊べるが再開はできない。

## ファイル

- `scenario.js`: 原作の台詞、手がかり、固定した原作の問題候補と正解。
- `game.js`: 状態遷移、入力判定、セーブ検証。
- `speech.js`: 音声ファイルの再生とブラウザ読み上げ・停止・重複防止。
- `audio.js` / `assets/audio/`: Gemini TTSで事前生成した音声と登録。未収録の回答はブラウザ読み上げ。
- `illustrations.js`: 紙の木・サンタ・箱のSVGと立体パーツ。手がかりの文字は画面側で描画。
- `app.js` / `styles.css` / `index.html`: 画面と操作。
- `reference/legacy-index.js`: ローカルの原作参照コピー。実行・ブラウザ配信・GitHub公開しない。公開版はこのファイルがなくても起動・動作検査できる。
- `SOURCE-NOTES.md`: 原作の流れ、照合行、ブラウザ向け変更の記録。
- `STORYBOOK-QA.md` / `AUDIO-QA.md`: 絵本とGemini音声の実際の検証結果・未確認項目。`QA.md` は初期画面版の記録。

## 音声

2026-10-05、ユーザーの「Gemini TTSためしていいよ」を受け、既存キーで制作時に生成。`gemini-3.8-flash-tts` を使い、サンタはAlgieba、語り手はSulafat。導入、箱の説明、四段階の手がかり、正解、誤答0000の八場面と短い試聴サンプルをWAVに保存した。遊ぶときは同じファイルを繰り返し再生し、生成APIやマイクを使わない。キーは配信ファイルに含めない。

0000以外の不正解には、その入力数字を含む同じ原作台詞をブラウザで読む。ファイル再生が失敗した場合もブラウザ読み上げへ戻る。この部分の声・品質は端末によって変わる。音声が使えなくても文字と操作で最後まで遊べる。実機スマートフォンの音質は未検証。生成結果に原文の読み落としや誤読がないかの全編聴取は未完了。

新しい契約・課金設定の変更はしていない。ただし既存キーの無料／有料枠と実際の請求は確認できていない。公開標準単価での今回の参考額は約0.055米ドル（実請求額ではない）。詳細と根拠は `AUDIO-QA.md`。

制作スクリプト `scripts/generate-audio.mjs` は通常の起動では実行しない。`--plan` はAPIを使わず対象を表示。`--sample` / `--all` は既存ファイルがない場合だけ外部APIを呼ぶ。`node scripts/verify-audio.mjs` はローカル検査のみ。
