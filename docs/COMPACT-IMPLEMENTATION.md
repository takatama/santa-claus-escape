## 維持する障害時の処理

音声の再生失敗、画像の読み込み失敗、ストレージの利用不可、音量を制御できない場合のミュートは、後方互換性とは別の機能として維持する。BGM形式の代替も、対応ブラウザの判断を伴う別変更とする。

公開一覧は最新mainですでに `pages-files.mjs` に一本化されているため、新しい公開一覧や別のビルド方式は追加しない。台詞・謎・答え・自由な箱順・全問誤答での救出・音声の読み込み順序とキャッシュは変更しない。
