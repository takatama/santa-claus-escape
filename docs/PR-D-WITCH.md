## 発見と音声

`SPELL`成功時は枝の画面へ進み、登場前には登場の台詞・字幕・効果音を出しません。初めて枝が開ききると、絵の描画後に既存の「しゃらららーん」（`shine1`）→登場会話を一度開始し、同時に「まほう使いと遊ぶ」「今は遊ばない」を表示します。枝を戻して開き直しても、その原文字幕・読み位置と再生中の声を保ち、自動再開始しません。発見は新しい謎や救出条件ではありません。

保存再開の`witchInvite`では登場会話・登場音を自動再開始しません。未登場の新しい途中保存は、再開後に初めて枝を開ききると登場音を開始します。登場後は「聞き直す」で明示的に再生できます。辞退・呼び直し・問題・返答は既存のシーンに接続。回答の明示送信と画面移動は`stop()`を通して古い声・効果音・予約を破棄します。入力編集・枝操作・BGM音量・効果音設定は判定や声の取消を行いません。停止・ミュート・やり直し・pagehide・非表示化も既存の取消世代を使い、遅い音声取得と登場の絵の取得待ちから再開しません。絵の失敗時も操作を止めず、文字と既存音声で続けられます。

新しい声・効果音・BGMは生成せず、`speech.js`、`audio-timeline.js`、`timed-audio.js`、`soundtrack.js`の音源・順序を維持します。

## 保存と旧保存の復旧

キーは`santa-claus-escape:ja-full:v2`、versionは2のまま。任意フィールド`witchDiscovery: {progress, pending, appeared}`だけ追加。`appeared`は初回登場の履歴で、音声予約ではありません。座標・カメラ・ドラッグ・選択・音声予約は保存しません。

- 未召喚では`null`。新しい成功では`{progress:0,pending:true,appeared:false}`。紙の並びを保持したまま直接発見へ進みます。
- 0〜1の有効な途中位置はそのまま再開。初めて0.98以上に開くと`appeared:true`になり、逆操作でも戻しません。「遊ぶ」または辞退を選ぶと`{progress:1,pending:false,appeared:true}`となり、枝を動かす古いイベントは受け付けません。発見中の逆操作は紙・登場履歴・回答を巻き戻しません。
- 旧Cの成功確認待ちは、その並びを保ったまま発見開始へ接続します。旧C／更新前Dには`appeared`がなく、当時は合言葉の成功時に登場音を再生していたため、登場済みとして復旧し、自動で登場音を追加しません。
- 旧保存が誘い・辞退・呼び直し・問題・返答・救出・完了まで到達していれば、情報の欠落・不正値を理由に発見前へ戻しません。到達済みの場面と回答履歴を優先し、枝を開いた表示へ復旧します。
- 有効な`pending:true`を持つ発見途中保存で、位置だけが欠落・非数値・範囲外なら0へ復旧します。`pending`自体が不正なら旧保存と同じ扱い。問題以降や再誘いで`pending:true`を渡しても発見へ戻しません。
- 旧`spellDraft`・配置保存・箱の保存の復旧規則を維持。壊れた本来の進行を任意フィールドで救済・開封しません。読み返しは既存の履歴から表示し、再読み込みでは完了済み進行に戻ります。
- やり直しは確認付き。キャンセルは入力と進行を保持。保存・絵・音が取得できなくても、そのセッションの操作と通し進行を止めません。
