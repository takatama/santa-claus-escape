# Issue #11 微修正

対象: https://github.com/takatama/santa-claus-escape/issues/11

## 実装

- 三箱一覧の本体幅と接地位置を、ふたの状態に依存しない `boxOverviewLayout` に統一。開いたふたの高さも最初から確保する。
- 紙の配置ログは視覚表示から除き、読み上げ支援用の live region として保持。「左へ」「右へ」「手元へ戻す」ボタンは削除。手元の紙をダブルクリックすると左から最初の空き枠へ配置する。タップ選択→枠、ドラッグ、矢印キー・Delete は維持し、選択した紙を手元の空きへタップして戻す操作を追加。
- 試行時のダイヤル効果音は main で除去済み。既存のタイムライン検査とブラウザの連打・キャンセル検査で維持を確認。ダイヤルを実際に動かすときの短い音と解錠音は残す。
- 青箱の資料末尾「この箱は、どちらの数字でも開きます。」を表示と読み上げから除く。8848 / 8849 の受理は変更しない。
- 声のバーは CSS の周期アニメーションから、実際の声の PCM サンプルと再生時計に連動する表示へ変更。効果音・BGM の再生系は観測しない。HTML Audio の音はそのまま再生し、同じ録音を既存キャッシュでデコードして視覚化だけに使う。デコードに失敗した場合や端末読み上げ時は静止表示となり、声の再生を妨げない。動きを減らす設定ではバーを固定する。
- 枝は左右同じ進捗で開ききる。つまみの水平位置を開始→終端の直線補間にして、枝の曲線変形による早すぎる端への張り付きを防ぐ。左右それぞれの実際の移動幅をドラッグ距離に使い、指の移動・逆戻し・つかみ直しを同じ計算に統一。
- 最初の問題は「10秒間、考えてみてね。」の後に10秒の無音を挿入。録音が使えず端末読み上げに切り替わった場合も同じ位置で待機し、停止・ミュート・画面移動で待機を取り消せる。回答操作を強制的に10秒ロックする仕様は追加しない。

## 先行リファクタリング

独立コミット `1a25861` で一覧用の箱レイアウトを描画から抽出し、音声タイムラインに録音の区間指定を追加した。この時点では従来の表示・音声を保ち、既存の単体テスト102件成功、2件スキップを確認した。

区間指定は、元の録音に対する秒数で切り出してから既存の無音処理・結合を行う。ゲーム状態や新しい保存層を導入せず、今回の音声編集値は `voice-edits.js` に集約した。

## 録音の編集位置

元の WAV / 配信用 M4A / 生成記録は変更しない。新しい声の生成や外部への音声送信は行っていない。作業用のローカル音声認識と、配信用音声の振幅を照合して文間を選んだ。

| 録音 | 処理 | 境界の根拠 |
| --- | --- | --- |
| `storybook-information.m4a` | 0〜21.65秒を再生 | 「書かれています」の後、21.45〜22.13秒の静かな文間。省く文は約22秒以降。 |
| `ja-leda-question-christmas-creatures.m4a` | 10.8秒で分割し、間に10秒挿入 | 「考えてみてね」の後、10.68〜10.85秒の静かな文間。続く「クリスマス」は約11.1秒から。 |

境界値はこれらの録音専用。録音を差し替える場合は再確認する。元の音声のハッシュ検査と配信派生物の検査を維持している。
