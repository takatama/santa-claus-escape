# PR B：青・黄の箱の統合

最終仕様は [Issue #3](https://github.com/takatama/santa-claus-escape/issues/3)。依存する [Draft PR A #4](https://github.com/takatama/santa-claus-escape/pull/4) の最新head `59a8d5cf840d2e2abe5b0a96f9ae786548f442bf` から開始。PR Aは未マージで、verify / browser / Cloudflare Pagesが成功。mainは `e4d225b`。PR BはPR AをbaseとするDraftで、mainへのマージ・本番公開は含めません。

## 調査と責務

PR Aの変更前の基準：`npm test` 49件成功、非公開原本照合のみ2件スキップ、Chromium E2E13項目成功。`full-game.js` が状態と保存、`full-scenario.js` が原文・答え・紙、`speech.js` / `audio-timeline.js` / `soundtrack.js` が音の正本です。PR #1 `aead6e9` の絵・雪払い・描画を参照し、別のjourney状態は取り込みません。PR #2 PRODUCT-DESIGN §8の大きな舞台・操作点・可逆操作・キーボード代替を参照します。4夜・家族の役割・儀式は対象外です。

まず赤の舞台を `box-stage.js`、台詞分割と予約を `box-presentation.js` に整理。`box-presentations.js` に絵・到達済み手がかり・操作名をまとめ、箱舞台の開始・終了、唯一の4桁入力、常設字幕、ふたのドラッグ・タップ・キー操作を共通化しました。構造整理のコミットは赤だけを統合した状態で検査しています。

青・黄のため、箱本体・ヒンジ・紙の描画を `box-art.js`、画像読み込みを `box-art-loader.js`、雪払いを `clue-snow-reveal.js` へ抽出しました。手がかりの描画・雪の安全境界・画像の比率・操作補助は色ごとのモジュールへ分離。必要になる責務だけを整理し、実行時依存や新しい状態ストアを追加しません。カメラ、雪の演出、音声予約、一手の閲覧位置はセッション内の表示情報。謎・紙授与・進行の正本と保存キー `santa-claus-escape:ja-full:v2` は維持します。

リスクは、古い音声予約の復活、雪の下の未到達ヒントの露出、旧保存にないふた位置の扱いです。既存の音声世代管理を使い、雪の各段階で次の領域を保護し、旧開封済みのふたは開いた状態へ復元します。

## 遊び方と色ごとの差

プレビューのルート `/` →「サンタを助ける」→「はい、箱を調べる」→「青色の箱」または「黄色の箱」。保存がある場合は「続きから」も使えます。URLと最新コミットに対応するCI・固定プレビューはPR本文に記録します。

青は山の絵、サガルマータ、その高さを端末で調べる手がかりの順に雪を払います。四段階目の紙の近くに「サガルマータについて調べる」を置き、既存の `INFORMATION` の原文・録音へ接続。元の資料の答え `8848` を保ちます。資料を見てもダイヤルの値は変わりません。

黄はグー、チョキ、パー、グー →「負けるが勝ち」→「指の数があなたをみちびく」の順。一手表示は手の絵が出る二段階目から任意で使えます。元の四つの絵を前後に拡大して見るだけで、未到達の文章・数字への変換・答え `2502` は表示しません。左右キー・Escape・「箱へ戻る」も利用できます。閲覧位置は保存するゲーム進行から独立しています。

三箱とも、調査中の錠と手がかりは固定サイズ。青は山と文章に合わせて紙を310px、赤と黄は300pxとし、各絵の比率を保ちます。雪は一押しで一段階、雪の演出中だけ連打を抑止。短く狭い横画面では舞台の内部スクロールで紙へ到達できます。常設字幕は別のスクロール領域で読み、数字や音声設定を変えても読んでいた位置を保ちます。

数字のタップ・ドラッグ・数字キー・上下キーは同じ四つのダイヤルに接続。「ためす」は現在の声・効果音・未再生の調査と判定を破棄して最新の入力を読み直します。同じ誤答の再試行でも再生し、数字を変えただけでは判定しません。停止・ミュート・箱から戻る操作も予約を破棄。箱から戻った後は元の三箱の案内音声を再生します。

解錠後は同じダイヤルを残し、視点を引いて手動のふたのつまみと方向表示を出します。ドラッグの途中停止・逆方向・途中保存と、同じつまみのタップ・Enter・Spaceを利用できます。紙の声と正解効果音はふたを開けたときに予約し、解錠の声の後に続けます。紙の授与と進行は既存の `opened` を正本とし、追加のふた情報で二重授与しません。旧保存の直接入力は有効な四桁を唯一の錠へ移し、ふた情報のない開封済み箱は開いた状態へ戻します。

## 素材と配信

青の三枚・黄の五枚はPR #1の参照headから無加工でコピー。出典、バイト数、SHA-256は [art-provenance.json](pr-b/art-provenance.json) に記録し、参照元と一致を確認しました。追加は **15,668,162 bytes（約14.94 MiB）**、三箱の計十一枚は **21,780,462 bytes（約20.77 MiB）**。青・黄はその箱を選んでから読み込み、赤の既存先読みを保ちます。低速回線・低性能端末での速度は未確認。絵を取得できなくても原文字幕と錠から続けられます。

`scripts/box-files.mjs` を開発サーバー・ビルド・配信検査の共通許可リストにしました。実行に必要な38ファイル、音素材91ファイル、絵11ファイルを配信します。文書・検査・制作記録は配信対象外。出典とクレジットは `NOTICE.md` に追記し、原作の声・BGM・効果音と利用条件を引き継ぎます。
