## 責務と進行

最初のコミットe4048a3でDの森・球・まほう使い・枝の配置と描画だけをforest-stageへ抽出。Dの66通常検査と枝案内→登場音→第1問のChromium回帰で基準線を確認。その後、rescue-stageは操作DOM、rescue-art / rescue-mathは単一サンタと開口の描画、rescue-presentationは既存の台詞と発話区間の接続を担当。状態と回答履歴の正本はfull-game、原文はfull-scenario、保存は従来の同じキーです。箱・紙・会話controller、journey/store、別の状態ストア・frameworkは複製しません。

三問目の返答は明示的な「サンタのもとへ」まで保持。新しいrescueへ入ると先頭の「うふふ。ああ楽しかった！」を表示・再生。球全体が約0.85秒で一度ふわっと光った後に、光のつまみを提示します。杖からの細い線は削除。演出は最初の救出への移動時だけで、保存再開・読み返しでは繰り返さず、低減モーションでは省略。演出の時間で救出や回答は進めません。右へ引いた指と同じ距離だけつまみが右へ移り、開口・サンタの移動、倍率と局所変形を共通の進捗へ接続。途中は停止・逆方向・中断でき、タップ / Enter / Spaceで一段階、左右キーで調整、Homeで開始位置、Endで完了。Escapeはその場でドラッグを中断。完了値1で解放とcomplete保存を同時に確定し、逆操作で回答や取得紙を巻き戻しません。スライダー・百分率・自由こすり・追加の正解条件・音声入力・家族儀式はありません。

森・球・まほう使い・開いた枝のカメラはDと共通。進捗0ではこれまでと同じ人物入りの球をそのまま描き、動き始めたら元の球の輪郭・反射・台座を保ち、サンタがいた内側だけ既存の空の球で補ったものと単一の不透明サンタを使います。人物入りの球と独立サンタを重ねません。元画像ファイルの変更や新規生成はありません。既存の球のサンタと独立素材は別の生成画像で細部の完全一致は保証しません。球の位置・倍率、顔の向き・手の姿勢の連続性と開始/途中/解放後の絵を実際にレビュー済みです。足と服の変形は試作由来で、自然な歩行の完成を主張しません。

## 音声・結末

原作の救出を先頭区間と解放後の区間へ分けます。先頭→0.5秒の後で、実際の解放完了を待つ→shine3→出現の声→0.5秒→既存rescue-dialogue→1秒→rescue-ending。速い完了でも先頭を切らず、先頭が終わった後に後半を一度開始。サンタが球内のまま出現の声を読みません。shine1はDの登場専用のままです。

声の終了は画面・回答を進めません。全原文は解放後に常設字幕へ出し、救出の操作だけでcompleteを記録して字幕へフォーカス。「サンタのお話を読む」ボタンは削除。「この絵本を読み返す」「最初から謎を解く」を表示し、同じ舞台のまま先頭と結末の音声を継続します。読み返し・確認付きやり直しへ接続。完了や保存再開に新たな鈴・物語はありません。

既存SpeechPlayer / AudioTimelineの取消世代を利用。途中操作、BGM・字幕・効果音設定は声を停止しません。停止・ミュート・離脱・やり直し・pagehide・非表示化は未再生の後半も破棄し、古い終了・失敗通知や遅い取得で復活させません。停止後にまだ未完だった救出を明示的に完了させた時、または聞き直し・続きから遊ぶでは、途中の音声予約を保存せず先頭から再生。操作中にAudioContextを準備します。

新しい画像が遅い時も、取得済みの森・球・人物を再利用して構図を保ちます。独立素材が使えない場合は球とサンタの簡易描画、文字と同じ操作でそのセッションを完了可能。画像取得を音声予約の開始条件にせず、遅い絵の取得は再描画だけ行います。音声・効果音の取得失敗は従来の同じ原文の読み上げ/文字へ戻ります。

## 保存と旧版

キー santa-claus-escape:ja-full:v2、version 2を維持。新しい任意のrescueMotion:{progress,released}だけを追加。座標・カメラ・ポインター・音声予約は保存しません。途中位置を復元し、解放確定は戻しません。旧rescue / completeの任意フィールド欠落・不正は解放済み{progress:1,released:true}として復旧し、救出操作の再実施を求めません。旧rescueの解放済み保存は「続きから遊ぶ」でcompleteを記録し、削除したボタンの操作を求めません。completeは必ず解放済み。読み返しのrescueも解放済みの同じ絵と原文を見せ、保存を変更しません。

本来の進行・箱開封・合言葉・三問の履歴の不正は、任意フィールドで救済しません。全問誤答、紙0枚、辞退と呼び直し、箱全六順序・三問全八正誤の経路を保ちます。保存不可でも進行・解放・完了はそのセッション内で可能です。
