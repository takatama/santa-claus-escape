## 残す検査

- Nodeテストは約1.5秒。全四桁・全箱順・回答組み合わせの網羅を削る利益は小さいため維持する。
- 7寸法には狭い縦、短い横、タブレット、デスクトップの異なるCSS条件がある。単に代表のスマホとPCだけには絞らない。
- 音声の通常再生・自然終了、HTML音声とWeb Audio、最初の音声と予約した結末、読み込み中と再生中の停止は異なる故障経路として残す。
- 停止・ミュート・リセット・ページ離脱の接続、ドラッグ・キー・タッチ、画像や保存が使えない場合の継続はブラウザで確認する。
- 450msの操作抑止をまたぐ待機、音が再開しないこと・装飾が進行を変えないことを観察する待機は根拠がある。数値を一括で短縮しない。
- AACの実デコードと原音との長さ比較は、ハッシュ照合だけでは検知できないブラウザ互換性の問題を扱うため残す。

## 画像保存

正常時の `page.screenshot()` は基準画像との比較を伴わず、CIの合否には寄与していなかった。通常は保存を省き、`SANTA_E2E_SCREENSHOTS=1 npm run test:e2e` で目視確認用に生成する。画像のピクセルを比較するassertionやCanvasの検査は省略しない。失敗時はPlaywrightがスクリーンショットとトレースを保存する。
