## 変更した体験

表紙・導入・三箱選択・救出以外の読み返しを、既存の森・球・箱の絵で構成する一つの舞台へ接続した。音声の常設操作盤は共通の「音の設定」内に置き、字幕と音声オン／オフは常設する。縦画面は絵・主操作・字幕、横長画面は絵と操作・右側の字幕という構成。字幕は内部でスクロールし、設定や音量を変えても読み位置を保つ。

三箱はすべて選べ、開いた箱や途中の箱を見直せる。箱の外観はA/Bの既存body/lid素材とふたの計算を再利用する。未取得の紙・ヒント・答えは表示しない。取得した紙は従来のID・色・読み上げ名を持つ。箱を開く順序と紙0枚での早期合言葉を維持し、入力中のIME変換では送信しない。

同日の追加補正で、三箱の前面に数字なしのダイヤル錠の外観を表示した。錠はふたの継ぎ目より下に置く。拡大画面のふた・本体の雪だけを `box-art.js` の共有描画へ切り出し、小さい箱にも同じ位置・質感で載せる。開いたふたの裏側には上面の雪を描かない。見つけた文字は、並べ替えの紙と同じ `#453a2b` のインク色に揃え、箱の色と紙の背景を維持した。

読み返しでは箱の到達した絵・紙・まほう使いを静止表示し、救出はEの読み返しを再利用する。操作・回答欄は表示せず、前後のページと終了の操作だけを提供する。履歴の閲覧は元の進行・回答・所有紙・保存を変更しない。

原文の漢字と主要操作語に表示層で読みを付ける。原文をひらがなへ置換せず、音声・問題・答え判定へ渡さない。登録語だけを扱い、未知の語を推測して変換しない。

## 承認された設定・青い箱・音声の変更

同日の相談で承認されたスノードーム設定を採用した。初出は「雪の入った、まるいガラス」と説明し、導入のサンタ・ひみつの言葉の伝え先・辞退後・救出の計5文、表紙・絵の説明・メタ情報を更新した。語り手は「お話の声」。原作の `scenario.js` と過去の台詞・音声を保持し、`storybook-content.js` の採用文を字幕・失敗時の読み上げ・履歴で共用する。

青い箱の紙と台詞は、ユーザー指定の「その名を調べよ。高さがカギを開く」。最後の調査に到達した後に「サガルマータを検索する」を表示し、山の名前だけをGoogle検索へ別タブで渡す。「資料を見る」は固定のゲーム内説明を開く。高さ8848／8849を両方正解にし、入力した数字を字幕・数字音声・保存・読み返しに反映する。旧版で8849を不正解として保存した状態は閉じたまま復元し、再度「ためす」を押すと開く。

必要な6点を既存と同じ声種（お話の声Sulafat、サンタAlgieba）で各一回収録した。辞退と救出の変更しない会話は、まほう使いLeda・サンタAlgiebaの元のPCMを再利用する。新しい6録音と2結合音声を `storybook-*.wav` として追加し、元の生成記録を上書きせず、対応する台詞・声種・使用量・ハッシュ・結合元を別のJSONに記録した。合計入力400・出力3,362トークン、計画上の出力上限9,728以内。ゲーム実行時のAPI・生成AI・マイクは使わない。

## 責務

- `prototype/story-stage.js`：残る画面のDOM、三箱の選択、早期合言葉の入力、IME、読み返しのナビゲーション。進行の決定は既存controllerへ渡す。
- `prototype/story-art.js`：既存の森・球・箱の外観、読み返しの静止画。既存の箱描画と`witch-art`を使用し、遅い取得は描画だけに反映。離脱後の取得は破棄。
- `prototype/box-art.js`：拡大と一覧で共通のふた・本体の雪描画。調査の雪払い・ヒント・開閉の計算は変更しない。
- `prototype/story-stage.css`：縦横の舞台配置、既存舞台と共通の文字・ルビ・ボタンの表示。
- `prototype/readings.js`：文脈別の語彙と表示用ruby。`rt`の読みはCSSの生成内容として描画し、アクセシビリティからは除外する。DOM本文・コピーの文字列は原文のまま。操作の読み上げ名は原文を明示し、動的ラベル変更にも追随する。
- `prototype/full-app.js`：既存状態に基づく舞台の選択と共通字幕の接続。置き換えた旧見開きの描画だけを除去した。
- `prototype/storybook-content.js`：承認された全編の台詞、検索URL、版を分けた音声ID。原作データと採用文の境界。
- `prototype/full-scenario.js` / `full-game.js`：青の正解候補・提出した数字の反応・保存の検証。状態と保存形式は追加しない。
- `prototype/box-presentation.js` / `timed-audio.js`：8849の音声経路と救出の差し替え。既存の数字収録・効果音・開閉順を再利用。
- `prototype/scripts/generate-storybook-voices.mjs`：6点の生成計画・一回生成・既存会話のPCM結合。過去の生成スクリプトは原作の場面を参照し、古い記録を再現できるようにした。
- `scripts/story-files.mjs`：新しい実行コード5ファイルの配信許可リスト。開発サーバーとPagesビルドへ接続。

保存キー `santa-claus-escape:ja-full:v2` / version 2、箱の自由順、六枚の紙、重複する「だ」のID、辞退／呼び直し、全問誤答でも救出できる分岐を維持。原作参照資料・他のプロトタイプ・未追跡のE引継ぎを変更していない。新しい画像素材・状態ストア・音声予約の保存・章・謎は導入していない。
