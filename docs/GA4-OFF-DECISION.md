# GA4を見送り、計測OFFで公開準備を進める

2026-10-13 JST。本人が「今回はGA4をOFFのまま、軽量化・OGP・共有・一般問い合わせを整えて公開準備を進める」という提案に「はい、そうしましょう」と回答した。以下を今回の方針とする。

## 採用した方針

- 今回の公開ではGA4を採用しない。本番・評価とも計測OFFを維持する。
- 軽量化、OGP、共有、元のゲームの進行・答え・音・保存は維持する。
- 一般問い合わせは既存の[Googleフォーム](CONTACT-FORM.md)。返信先は任意、対応完了後30日以内に情報を削除する。GA識別子を受け取る用途へ変更しない。
- 改善は、まず少人数のプレイ観察と保護者からの任意の感想を利用する。試遊の新規募集や誰かへの連絡を、この決定だけで実施するものではない。
- mainマージ・本番公開・英語版制作は今回の作業に含めない。サブエージェントを使わない。

子ども中心、広告・収益化なし、個人の趣味、将来の米国/EU/英国への提供という前提で、得たい改善情報に対する追加の実装・運用負担を理由に見送る。子ども向けのGA4が一律禁止と確認できたための決定ではない。

## 今回の導入予定から外すもの

GAの有効化、Realtime/DebugViewへの実送信、GA用の年齢/保護者確認UI、同意台帳、GA個別削除の専用受付、D1、Pages Functions、管理Worker、GAS通知、Googleフォームへのclient_id受付、事前入力URLを用意する作業は進めない。これらの仕組みは実装・配置・送信していない。

既存のGA準備コードは無効のまま残す。削除するためにゲームや共有の処理を変更しない。ビルド時の `SANTA_GA4_POLICY_APPROVED=false` を維持し、測定IDや評価originを保存していても有効化しない。Cloudflare Web Analyticsもdisabledを維持する。既存のGAプロパティ・DPA連絡先・設定を削除したり、本人へ設定のやり直しを求めたりしない。

無効な計測コードが残ることと、計測を導入予定として扱うことを分ける。将来の誤った有効化を避けるため、公開するプライバシー説明からGA4の有効化・Cookie保持・個別削除受付の予定を取り除き、設定文書と確認表へこの決定を明記する。

## 残る公開準備

現在の対象は日本語版。[公開確認表](RELEASE-CHECKLIST.md)に沿って、一つずつ必要な確認を進める。

| 対象 | 次に扱うこと |
| --- | --- |
| スマホの通しプレイ | 実機で表示・音・保存/再開・共有を確認する。ブラウザの自動検査を実機確認に読み替えない |
| 素材の利用条件 | Gemini事前収録音声の現状の静的配信は2026-10-13に運営者が了承。公式回答の取得を必須作業から外す。結末の鈴も不使用のため許諾確認を残作業から外す。出典・クレジットと調査記録は保持する |
| 現在のプライバシー説明 | 端末保存、一般問い合わせ、Cloudflareの配信、外部リンク/共有を日英で説明する |
| 英語版と海外への紹介 | 英語版完成後の計画。具体的な対象国・告知・説明をその段階で確認する |

GA4を見送ることで、ホスティング・一般問い合わせ・作品の公開条件まで確認済みになったとは扱わない。過去のGAデータが別に存在する場合の対応も、今回の新規計測の見送りとは別。

2026-10-13の追加判断：本人は基本的にゲームを利用できていると報告した。細分化した追加の操作案内は終了する。Gemini事前収録音声も運営者の判断で現状の利用を了承し、問い合わせ回答の取得を公開前の条件にしない。公式見解の取得や各端末・支援技術の個別検査結果がない項目は、確認済みに書き換えない。これらを繰り返し本人へ追加確認する作業は今回の対象から外す。
