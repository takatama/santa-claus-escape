**青・黄の機能を自然に組み込むため、必要な範囲をリファクタリングしたうえで実装してください。** 独立した大掃除を先に済ませることが目的ではありません。

2. 青・黄の実装に必要な共通部分と色固有の部分を見極め、変更範囲、再利用コード、リスクを短く報告する。
3. その機能に必要な責務の境界を先に整え、赤い箱の挙動を維持する。その上で青・黄の機能を追加する。構造整理と機能追加はレビューできるコミットに分けてよい。

`full-app.js` に色ごとの条件分岐を積み重ねたり、赤い箱のcontroller／viewを丸ごと複製して無理に埋め込んだりしないでください。一方、まだ必要性がない汎用エンジン、新しいframework、全面的な書き直し、無関係な整理はしません。

## PR Aで確定した操作・画面

- 調査中は錠とヒントを読める大きさに保ち、窓の大きさだけで箱が縮んだり膨らんだりしない。周辺が画面からはみ出してよい。解錠後は手動でふたを動かせる構図にする。
- 雪払いは**ボタン一押し一段階**。原作の各箱の4段階・順序を守り、連打で飛ばさない。PR #1の払う動きと質感を活用し、自由こすりに戻さない。
- 4桁の表示・入力は箱に付いたダイヤルだけ。タップ／ドラッグ／数字キー／キーボードの代替操作を同じ値に接続し、別の入力欄を並べない。ダイヤルに上下矢印の絵を追加しない。
- 「ためす」は錠の直下で明るさ・厚み・押下の変化により押せる見た目にする。ヒントとの間に余白を作り、「調べる」は調べる対象の近くに置く。
- 原作の台詞を常設のスクロール領域で読めるようにする。大きなスピーカーと動くバーで再生中を示す。これは再生状態の表示で、マイクや実音量の測定ではない。低減モーションも維持する。数字・音声設定の変更で読んでいた位置を失わない。
- 音声が終わる前も操作できる。「調べる」は声を順に予約し、雪の演出だけが一時的に次の段階を抑止する。**「ためす」は現在の声・効果音・未再生の調査と判定を取り消し、最新の入力の結果へ切り替える。** 同じ入力の再試行でも読み直す。数字を変えるだけでは判定・中断しない。
- 旧再生の終了通知や読み込み完了から古い声・効果音・字幕・判定を復活させない。停止・ミュート・箱から戻る場合も予約を破棄する。音声不可時も文字で進行できる。
- 解錠したら**人間がふたを開ける**。大きなつまみと動く方向の矢印を操作点にし、途中停止・逆方向・途中保存と、同じ操作点のタップ／Enter／Spaceの代替操作を維持する。別の開閉ボタンや説明文を重ねない。
- 解錠後もダイヤル錠の姿を残す。チェックマークに置き換えない。雪の上へ意味のない金色の輪郭を追加しない。紙の声・正解音はふたを開ける操作で予約し、解錠の声の後へ続ける。

## 青・黄の固有仕様

- 青は原作の山の絵、「サガルマータ」、「その高さは、この端末が知っている」の順に調べる。既存の `INFORMATION` と原作の資料・音声へ迷わず到達できる導線を維持する。原作の答え `8848` を事実の更新などを理由に勝手に変えない。
- 黄は原作の「グー、チョキ、パー、グー」、「負けるが勝ち」、「指の数があなたをみちびく」を守る。Issue #3にある、一手ずつ絵を見て考える補助を、この謎を壊さない範囲で具体化する。答え `2502` の自動入力・数字への自動変換・未到達のヒントや正解の開示はしない。
- 既存の台詞、問題、正解、音声・BGM・効果音、箱の自由順、紙の二枚ずつの授与、全問誤答での救出、魔法使いを断って呼び直す経路を守る。保存キー `santa-claus-escape:ja-full:v2`、旧セーブ、続きから、初期化確認を維持する。追加のふた情報は旧保存と互換に扱う。
- 新しい物語・新しい謎・家族で合言葉を唱える儀式・人数や声が必要な進行・マイク・AIは追加しない。新しいアイデアは実装せず別案として報告する。
