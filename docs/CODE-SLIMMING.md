# 旧試作コードの整理と記事用資料

2026-10-18。Cloudflare本番のルートHTMLと、`full-app.js`・環境アニメーション・各場面の主要描画コードの計8ファイルが、整理前のローカル公開成果物とバイト単位で一致することを確認してから整理した。全配信素材の照合や本番の再デプロイは行っていない。

## 現行版の構成

現行のアニメーションあり統合版を、旧名 `prototype/` から `game/` に移動した。起動・ビルド・テスト・制作スクリプトと文書リンクも更新する。公開URLと `dist/` 内の構成は変えない。過去の計測JSON・素材の来歴JSONに残る `prototype/` は当時のパスであり、現在のファイルを参照する際は `game/` と読み替える。原本照合テストもこの対応を適用し、記録済みのハッシュ・バイト数は変更しない。

- 入口：`game/index.html` → `game/full-app.js`。
- 進行・保存：`full-game.js`。現行セーブ形式と旧体験版からの保存データ移行を維持。
- 台詞・音声：`full-scenario.js` / `full-audio.js` と共通の `scenario.js` / `audio.js`。旧収録の台詞・音声も現在の版や生成記録の照合で使用する。
- 描画：各 `*-stage.js` / `*-art.js` と `atmosphere.js`。降雪・人物・紙・救出の演出を維持。
- 公開：`npm run build` で許可リストにあるファイルだけを `dist/` に出力する。

## 削除・縮小したもの

- `game/app.js`：赤箱だけを遊ぶ旧体験版の画面とイベント処理。
- `game/game.js`：旧体験版専用の進行・保存処理。現行版の `full-game.js` には依存されていない。
- `game/illustrations.js`：旧画面専用のSVG・紙細工風描画。現行のCanvas版では未使用だったが、公開許可リストに残っていたため同リストからも除いた。既存の `dist/illustrations.js` だけは次のビルド時に除去し、その他の想定外ファイルを拒否する従来の検査は維持する。
- 共通CSS：旧画面の本・紙細工・旧ダイヤル・旧箱選択など、現在のコードが生成しない要素の指定と専用キーフレームを削除。共有UI、台詞、音の設定、読み返し、プライバシーページ、OSの動きを減らす設定は維持。共通CSSは33,465バイトから9,560バイトへ、約71%削減。
- 旧画面の音声表示更新、旧音声キーを作る未使用関数、開発サーバーの旧 `app.js` 配信を削除。
- 旧状態管理だけを検査する4テストを削除。共用の読み上げ・録音・原本照合テストは `game/tests/speech.test.mjs` に移して継続する。

削除済みの実装そのものを記事で参照する場合は、この変更前のGit履歴から読める。原本・素材・制作スクリプトや記事資料の削除は行わない。
