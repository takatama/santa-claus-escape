## 紙の操作と成功

表紙 →「サンタを助ける」→「はい、箱を調べる」→好きな順で三箱を解き、各ふたを手で開ける → 最後の「ひみつの言葉を考える」で紙の画面へ。

- 通常の六枚取得経路は紙の並べ替えだけを表示。別の合言葉入力欄は併設しません。
- 紙をつかんで枠へ置く。置く先は明るい枠、選択は紙の縁で表示します。配置済みの紙を占有枠へ動かすと交換、手元の紙なら元の紙が手元へ戻ります。手元へドロップ、または「手元へ戻す」で戻せます。
- 紙を選ぶ → 枠を押すタップ代替があります。Tab / Enter / Spaceで選択・配置、左右キーで移動・交換、Delete / Backspaceで復帰、Escapeで中断。ドラッグ不要・発声不要で完了できます。
- 枠外、pointercancel、捕捉喪失、Escape、ウィンドウの非表示・フォーカス喪失・サイズ変更・スクロールによる中断は、配置を変更せず元の場所へ戻します。操作中にDOM全体を作り直しません。
- 紙の移動は判定も音の中断も起こしません。「この並びで伝える」が明示的な送信です。空・未完成・誤答は色付きの説明で見直せ、配置を保持します。
- 正解は原作の「だいすきだよ」。どちらの「だ」を先に使っても同じ判定。自動整列・正解吸着・未取得文字の開示・正解順の誘導はありません。
- 成功は紙を金色にし、成功文と並びを保持。「まほう使いに会う」で既存の場面へ進みます。タイマーによる遷移はありません。連打・古いrevision・再開から二重召喚しません。
- 送信時に既存の `SPELL` を実行し、原作の召喚音・登場の台詞を開始します。確認操作は同じ登場場面の表示を切り替えるだけなので音を重ねません。辞退・問題など別の場面への移動は既存の停止処理へ接続します。

三箱画面の「ひみつの言葉が、もう分かったら」は維持します。紙0枚から旧入力で召喚・辞退・保存再開・呼び直し・全問誤答の救出ができます。召喚を理由に箱を開けたり紙を授与したりしません。紙の絵でもサンタは球内。まほう使い三問・枝・発見・救出・結末の新画面、4夜・家族役割・儀式・マイク・AI・新しい謎・物語は追加しません。別案として実装を提案する新しい遊びもありません。

## 保存と字幕・音

保存キーは `santa-claus-escape:ja-full:v2`、versionも2を維持。追加は `spellSlots`（六枠の紙IDまたはnull）と `spellReview`（成功表示の確認待ち）です。同じ進行状態内で管理します。

- 新しい途中配置はそのまま保存・復元。成功確認待ちも復元し、召喚を再実行しません。
- 配置フィールドのない旧保存は、**その人が保存した** `spellDraft` を既存の正規化へ通し、文字位置ごとに取得済みの未使用IDを当てます。未知の文字は空の枠、6文字より後は配置対象外。漢字は紙で表せる文字だけ復元し、元のdraftは保持。正解へ自動修正しません。
- 重複・未知・未取得ID、六枠以外、文字列やオブジェクトなど不正な配置は、**六枠全部を空に戻し、既存の進行・紙取得・draftは保持**。正しい旧保存まで初期化しません。不正な追加情報から開封・召喚・救出を増やしません。
- 確認待ちは初回の `witchInvite` と正しい一意の並びに限って復元。配置が壊れた召喚後の保存は既存のまほう使い画面へ戻します。辞退後は保存された配置を保ち、既存の呼び直しへ進めます。
- やり直しは確認ダイアログを使い、キャンセルは配置を保持。保存不可でも同じページ内で通し進行できます。

原作の六文字の説明中にも紙を操作できます。字幕は常設・内部スクロール、縦は下段、横長は右側。紙移動・ミュート・BGM音量・効果音設定・聞き直し・停止で読み位置を保持し、台詞が変わった時だけ本文を更新します。音の設定内の開いたクレジットと操作フォーカスも保ちます。再生中のスピーカーとバーは既存の状態表示、低減モーションでは静止。実音量計測やマイクを使いません。原作のBGM・効果音・結末を保ち、新しい声や音は生成しません。
