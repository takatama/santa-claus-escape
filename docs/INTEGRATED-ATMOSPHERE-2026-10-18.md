# 現行版への環境演出の移行と旧試作の廃止

## 反映先

`origin/main` の `8ca4da8` を基点に、現行の `prototype/` へ反映。入口はルート `/` → `prototype/index.html` → `full-app.js`。同名の旧試作画面を現行版と取り違えないよう、独立した `illustrated-prototype/` を削除した。

旧試作の公開許可リスト、コピー処理、専用CI、調査用起動サーバーも削除。旧 `/illustrated/` と旧 `/blue-box/index.html` 等は404とする。ビルドに旧出力が紛れた場合は、現行ファイルを上書きする前に検査で止める。

READMEとAGENTS.mdに現行の作業先を明記。過去の設計・検証記録と素材出典のパスは歴史的参照として残す。採用済み画像・音声は `prototype/assets/` に独立して存在し、原本・配信用派生・ハッシュを変更していない。旧制作情報はGit履歴の `aead6e9` と既存の `docs/pr-*/art-provenance.json` から参照できる。

## 演出

- `atmosphere.js` は雪・球内サンタの小さな局所変形・演出用の時計・停止操作を担当する。ゲームの状態や保存形式には触れない。
- 森の描画は `story-art.js`、発見・会話は `witch-art.js` に接続。雪の大きさ・速度・密度を三層に分け、顔の前では薄くする。サンタのガラス外周・台座・足場は固定する。
- まほう使いは一枚絵の顔・髪・裾を7.2秒周期で局所変形する。パーツ分割ではなく、表示上約1px程度の控えめな動き。杖の光も明滅する。枝の開閉進捗、ドラッグ停止・逆戻し、台詞や正誤判定と独立させる。本格的な分割・かわいらしい登場は次セッションへ引き継ぐ。
- 紙を並べる画面にも背景の雪と球内サンタの動きを追加。受理された紙の移動だけに短い着地反応を付ける。
- 救出には独立した透明SVGで雪とドラッグ量に連動する光を重ねる。解放後の光は約2.2秒で収束し、完了画像では画像の領域内だけに雪を描く。動きを減らす設定では初期停止し、解放後の余韻も省く。
- 完了画面の読み返し・共有・再開ボタンを中央にまとめる。通常の最大幅520px、低い横画面では最大786pxとし、広い画面で左右へ散らばらないようにする。
- 箱から森へ戻るときの特別なサンタの反応は、ユーザーの指示により削除した。再導入しない。
- 箱を調べる・開閉する画面は従来どおり `box-stage.js` / `box-art.js`。箱の拡大構図にスノードームや環境アニメーションを追加しない。
- 停止・再開は同じタブで維持する演出専用sessionStorageキーを使い、ゲームのlocalStorageには書かない。OSの動きを減らす設定では初期停止。非表示・画面外・離脱・ステージ破棄でループを停止し、休止時間を飛ばして再生しない。
- 森・枝の静止描画とサンタの変形画像はキャッシュする。最大30fpsを目安に描画する。画像生成や新規の外部通信はない。

## 検査

`prototype/tests/atmosphere.test.mjs` は停止・再開、演出専用設定、動きを減らす設定、表示状態、後始末を検査する。

`tests/browser/atmosphere.spec.js` は実際の画素変化と停止時の一致、進行データの不変、320/390/1280pxでの配置、三色の箱の開閉、発見・一問目、旧URLの404を検査する。既存のブラウザーテストとともに実行する。

確認結果：`npm test` は113件成功。設計モデル2,592経路、音声、素材のハッシュ、公開対象、ビルド、HTTP配信検査も成功。

ブラウザー全体138件を2並列で実行した初回は135件成功、3件失敗。停止ボタンの追加で320px時に設定が折り返す実不具合は、見出し幅・設定の一行表示を修正した。短い案内音声の中断検査は、既存のバッファ音源と同様にテスト用再生速度を0.25にして自然終了との混同を防いだ。本体の再生速度・音声処理は変更していない。会話の7サイズ検査は90秒を超えたため、既定の1並列で再確認した。

最終ビルドに対し、失敗3件と演出・読み込み失敗の関連項目を合わせた12件を既定の1並列で再検査し、すべて成功。会話7サイズ検査は52.3秒で完了。主操作・設定が画面内に収まること、箱の拡大構図にスノードームが出ないことをスクリーンショットでも確認した。

追加の `atmosphere-scenes.spec.js` は紙の着地・停止、箱からの復帰、救出の巻き戻し・余韻・完了画像のクリップ・動きを減らす設定を検査する。`completion-layout.spec.js` は320pxから1920pxまでの完了画面を検査する。追加後の対象ブラウザー16件、単体113件、ビルドと配信検査は成功。マージ前の全体CI結果はPRで確認する。

旧試作の残存比較ベンチとローカルに退避した旧ビルドも整理する。制作時の既存未コミット変更を含むstashは保全し、ゲームや通常の起動から参照しない。

人物の本格的な部品分け、新ポーズ、まばたきは今回の範囲外。スマートフォン実機の発熱・電池消費は未確認。ユーザーの2026-10-18の指示により、この変更は検査後にPRを作成してマージする。次の作業は [まほう使いの引継ぎプロンプト](WIZARD-ANIMATION-HANDOFF.md) を使う。
