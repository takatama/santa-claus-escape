# まほう使い：全身一体版（2026-10-18）

首が不自然にずれるとのユーザー指摘を受け、帽子・顔・髪・首・体・裾・足を分けた旧案は撤回しました。

帽子から足までつながった「口を閉じた全身」と「にっこり笑う全身」を用意し、手首から先だけを独立して動かします。杖側の腕も全身画像の一部です。首や顔の取付位置・個別回転・貼り合わせはありません。表情の切替は全身画像の交換で、すべて同じ描画枠を使います。生成画像ごとの差で服・帽子がフラッシュするのを防ぐため、承認済みの全身を共通の土台にして目・口の領域だけを境界をぼかして事前合成します。表情ごとにキャッシュした全身画像を一枚として描画し、首や顔を別々には動かしません。目・口の周辺以外のRGBA差と全画素の透明度差が0であることをブラウザーテストで検証しています。目と口を閉じた全身画像も追加し、手振りの山に合わせて約0.16秒ずつ2回だけ切り替えます。動きを減らす設定では表情を切り替えません。まほう使いとの3問すべてにも反映し、問題の開始時と回答への返事で軽い手振り・閉じた表情を短く入れます。待機中は手を止め、約5.6秒ごとに約0.18秒の表情切替だけを行います。

初登場の跳躍・着地・返事の傾きは全身を一緒に動かします。手の大きさを従来の約72%にし、手の位置は保ち、手首の回転支点だけを上に調整しています。手振りは最大約8度の小さな動きに抑えています。ジャンプは全身の形を変えずに一度だけで、着地後の沈み込み・跳ね返りはありません。待機中の首かしげ・顔だけのまばたき・帽子や裾の個別変形は削除しました。

既存の発見効果音→台詞、初回のみの登場、枝の途中停止と逆戻し、保存形式、動きを減らす設定、非表示／画面外／離脱／破棄の扱いは保持しています。音源・台詞・正解・ゲーム進行は変更していません。
