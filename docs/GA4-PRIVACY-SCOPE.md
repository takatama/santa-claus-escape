# プライバシー対応の範囲：計測OFFと海外公開

2026-10-13 JST更新。ユーザーは**米国・EU・英国へ積極的に公開する**意向。子どもも遊べる作品、広告なし、GA4は無効のまま。EU内の具体的な対象国・提供言語・告知方法は未確定。国内、米国、EU/EEA、英国について整理する。他の国や米国州法を含めた全地域の確認が完了したという意味ではない。

追加確認：**個人の趣味として無料公開し、子どもの利用を想定する**。本人が完了したGA管理設定と、趣味公開についての適用判断は[設定の進捗と前提](GA4-SETUP-PROGRESS.md)に記録した。管理設定の完了を法令・規約への適合や有効化の許可に読み替えない。

## 今の作業と、公開までの準備

設定箇所と対応範囲を文書化し、ユーザーが作成・動作確認した外部の問い合わせフォームへのリンクを反映する。ゲームに年齢入力、身分証確認、保護者登録、同意管理サービス、埋め込みフォームやサーバーは追加しない。**使っていないGA4のために、計測有効時の仕組みを先にすべて実装する必要はない。**

GA4なしで公開する場合にも、ホスティング等の情報処理と対象地域への対応は残る。以下はこの実装からの運用提案であり、各国の義務の適用を確定したものではない。

| 対象 | 計測OFFでの公開前に整える範囲 | 現状・残る作業 |
| --- | --- | --- |

| 運営者と連絡 | 運営者表示、個人情報を公開させずに相談できる窓口、問い合わせ情報の最小化 | 高玉 広和 / Hirokazu TakatamaとGoogleフォームへのリンクをローカルへ反映。返信先は任意、対応完了後30日以内に削除。[窓口の確認記録](CONTACT-FORM.md)。GAデータの対象特定は未解決 |
| 配信と情報処理 | Cloudflareの配信に伴う情報処理、適用される契約・保存・移転・権利対応の確認 | Cloudflareへのリンクはある。自分の契約・設定に基づく処理の範囲と運用は未確認。GA無効を「一切収集しない」と言い換えない |

Cloudflareはウェブサイトの配信等に伴うEnd Usersの情報処理も説明している。[Cloudflare Privacy Policy](https://www.cloudflare.com/privacypolicy/)。第三者のポリシーへのリンクだけで、自分の利用目的・窓口・権利対応の説明が完成したとは扱わない。

GA4を実際に利用しない間はGA Cookieも発行しないため、GAのための初回Cookieバナーや過去GAデータの削除依頼UIを先に作る根拠はない。過去に取得したGAデータがある場合の義務は別。必要な端末保存と計測の区別、Cloudflare側の処理、地域別の法令適用は確認する。

## GA4を有効にする前に必要なこと

以下は現在の実装方針での有効化条件。法律上の義務、Googleの契約条件、この作品の運用条件を混同しない。

1. **対象地域と子どもの扱いを確定する。** 国、告知・提供言語、対象年齢、運営の性質を記録し、下表の条件を評価する。解析の例外を使えるか、保護者同意が必要かを未判断のままフラグを立てない。
2. **説明と任意選択を実運用に合わせる。** Googleへの送信項目・目的・Cookie・保持・受領者を表示し、拒否しても同じゲームを遊べるようにする。子どものクリックを検証可能な保護者同意の代わりにしない。条件が必要とする場合はUI・運用を別途設計する。
3. **海外向けのプライバシー通知を完成する。** 対象者が読める言語で、運営者と非公開連絡先、目的と適用される処理根拠、送信先・項目、保存、国外移転、利用者の権利・苦情先を必要な範囲で説明する。GoogleとCloudflareの契約・データ処理条件を確認する。
4. **受付と削除を運用できるようにする。** [削除手順](GA4-DELETION-PROCEDURE.md)の窓口・対象特定・返信を整える。識別子が失われた対象を必ず特定できるとは約束しない。解除、端末Cookie削除、Googleへの削除依頼は別の処理。
5. **GA管理設定を確認する。** シグナル・広告パーソナライズ・広告連携・拡張計測をオフ、イベント保持2か月、共有設定は必要最小限。コード上の広告無効化だけで、管理設定の確認を済ませない。2か月はCookie期限180日や集計レポートの保持とは別。
6. **同意・拒否・取消しと実通信を検証する。** 現在の設定欄、同意記録の方法、取消しの導線が対象地域の条件を満たすか確認する。必要な記録のために独自識別子を無断で増やさない。評価環境での本人確認を子ども向け本番の承認へ転用しない。

Googleは適切なポリシー公開、GAとCookie等の説明、法令で必要な同意を契約条件として求める。[Google Analytics規約 §7](https://marketingplatform.google.com/about/analytics/terms/jp/)。条件未確定の間はProduction・Previewとも`SANTA_GA4_POLICY_APPROVED=false`または未設定を維持する。

## 国・地域ごとの確認

| 地域 | 公式資料から確認したこと | この作品で未確定のこと |
| --- | --- | --- |
| 日本 | Cookie識別子は通常個人関連情報となり、法第31条はすべての提供に一律適用されない。[個人情報保護委員会Q8-1・Q8-3・Q8-10](https://www.ppc.go.jp/personalinfo/faq/APPI_QA/)。外部送信規律は対象サービス等の条件と通知・公表等の方法を定める。[総務省FAQ](https://www.soumu.go.jp/main_sosiki/joho_tsusin/d_syohi/gaibusoushin_kiritsu_00002.html) | 運営形態と実際のデータフローに基づく適用判断。オンラインゲームだから自己発信サイトと同じ扱いで対象外、と決めない。同意バナーが常に必須とも決めない |
| 米国 | COPPAは13歳未満、child-directedなサービス等、永続識別子を扱い、国外事業者にも適用される場合がある。内部運用の解析には限定した例外がある。[FTC FAQ A・J](https://www.ftc.gov/business-guidance/resources/complying-coppa-frequently-asked-questions) | 対象となる運営か、子ども向けの該当性、Google等の利用・再利用・保持を含め例外に収まるか。広告OFFだけで例外を満たしたことにしない。米国向けを含める意向でも適用の具体的判断は未完了 |
| EU/EEA | 国外からサービスを提供・行動をモニターする場合にもGDPRが適用され得る。[欧州委員会の適用説明](https://commission.europa.eu/law/law-topic/data-protection/information-business-and-organisations/application-gdpr_en)。子どもへ直接提供するオンラインサービスで同意を処理根拠とする場合、保護者同意の年齢は国により13〜16歳。[欧州委員会の子ども向け説明](https://commission.europa.eu/law/law-topic/data-protection/information-business-and-organisations/legal-grounds-processing-data/are-there-any-specific-safeguards-data-about-children_en)。解析Cookieの同意例外には条件がある。[CNILの解析ガイド](https://www.cnil.fr/fr/node/677) | 実際の対象国・言語・告知方法、各国のCookie条件、子どもの同意の方法、処理根拠、権利対応、Google/Cloudflareへの国外移転、必要な代理人等。GA4を同意不要の解析と認定していない |
| 英国 | 子どもが利用しそうなオンラインサービスもChildren's codeの検討対象となり、子ども専用に限られない。[ICOの対象サービス説明](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/childrens-information/childrens-code-guidance-and-resources/age-appropriate-design-a-code-of-practice-for-online-services/services-covered-by-this-code/)。2026-04-29のPECRガイドには統計目的の例外があるが、目的・集計・保持・通知・簡単で無料の異議手段等に条件がある。[ICOの例外説明](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/guidance-on-the-use-of-storage-and-access-technologies/what-are-the-exceptions/) | 英国への提供、UK GDPR・Children's codeの適用、年齢の扱い、必要な影響評価。イベント明細の保持や記事への利用を含む今回の構成が統計例外に収まるか。例外があってもUK GDPRへの対応がなくなるとは扱わない |

## 今回追加しないものと、判断が必要な場合

| 仕組み | この段階の判断 |
| --- | --- |
| 生年月日・身分証・保護者アカウント | 追加しない。保護者同意等が必要になった場合、取得を増やす案と計測OFF継続の負担・利益を比較してから判断する |
| CMP、国別判定、サーバー側の計測 | 導入しない。現在の選択UIで不足する条件が確認された場合に別途検討する。サーバー経由なら同意不要とはしない |
| 独自User-ID・プレイID | 追加しない。厳密なプレイ回数のファネルのために識別を増やさない |
| 国別の年齢・同意判定フラグ | 現在の一つの承認フラグはこれらを判定しない。国・地域の制限や条件付き計測が必要なら別途設計し、範囲を確認する |
| 本番での試験計測 | 行わない。評価を行う許可も今回は与えられていない。公開プレビューは成人限定を保証しない |

条件が整うまで海外向けもGA4をOFFに保つ方針が、今回のユーザー指示と一致する。GAの新規収集の課題を増やさず、軽量化・OGP・共有の準備を進められる。ただしホスティングの情報処理、作品の公開条件、Gemini事前収録音声の静的配信の年齢条項は別であり、GAをOFFにして解決したと扱わない。[公開確認表](RELEASE-CHECKLIST.md)の未解決事項を維持する。
