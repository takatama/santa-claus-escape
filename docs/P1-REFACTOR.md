# P-1: GA4・素材圧縮の準備

全編統合済みの main (`99b8cf4572cb2ca45ba905145571c28a58072c5b`) を基準に、素材参照、出来事の抽出、配信一覧だけを整理した。GA4通信、実素材の変換、保存・状態遷移の変更は含まない。

## 素材参照

`prototype/media-assets.js` の `MEDIA_GROUPS` に音声・画像の参照先、拡張子、ID一覧を集約した。グループの `base` / `extension` でまとめて変更でき、`overrides` で一部のファイル名だけ指定できる。BGMは既存のOGG能力判定とWAVフォールバックを同じ位置に残す。

`mediaPath(group, id)` は従来と同じ相対URL、`mediaUrl(group, id)` は画像用の絶対URLを返す。URL生成は純粋な処理で、fetch、画像生成、デコード、再生を行わない。呼び出し元の読み込み時点、Promise共有、失敗時の再試行、音声キャッシュは既存の処理を使う。

現段階の配信対象は従来と同じ音声100件・画像18件。既存の収録バリエーションも保持する。将来の変換では、この一覧から旧形式を外すことで、元ファイルを制作資料として残しても配信に含めない。配信MIMEは未知の素材拡張子を検査で拒否するため、追加形式に対応する際は明示的に登録する。

## 出来事の抽出

`prototype/game-events.js` の `extractGameEvents(previous, next, action?)` に、同じ既存 `transition()` 呼び出しの直前・直後の状態を渡す。復元された保存データや `readingState()` の投影は入力対象にしない。関数は状態を変更せず、保存・通信・イベントの保持も行わない。現段階ではゲーム本体へ通知処理を接続しない。

出力は `type` と必要最小限の値だけを持つ中立的なレコードであり、GA4のイベント名・送信仕様ではない。開始、箱の選択と判定、ひみつの言葉の成立、まほう使いの初登場・選択・再呼び出し、三問の判定、救出開始・解放・完了、リセットを抽出する。回答数字、自由入力本文、保存内容は出力しない。

採用された誤答の再試行は同じ数字でも抽出する。無効入力、古いrevision、入力編集中、音声、設定、紙やつまみの中間移動では出来事を出さない。リセットはrevisionが0に戻るため `action` が必要。現在の救出は解放と完了を同じ遷移で出し、解放済みの旧保存からの `FINISH` は完了だけを出す。

## 配信一覧

`scripts/pages-files.mjs` が、既存の画面別コード一覧と素材カタログから公開対象を組み立てる。ビルド、開発/Pagesプレビュー、ローカル配信検査、PRプレビューの実配信比較が同じ一覧を使う。

ビルドは一覧のファイルだけをコピーし、未知の既存distファイル・フォルダは従来どおりコピー前にエラーにする。自動削除は行わない。配信検査はdistから期待対象を発見せず、共通一覧に対して不足・混入を検査する。HTTPヘッダー、Cache-Control、音声Range処理は維持する。

## 検証

変更前のビルドを固定して既存Chromium E2Eを実行し、変更後のビルドでも同じ全件を実行する。通常テスト、設計モデル、既存音声、公開対象、ローカル配信も確認する。追加テストは、純粋関数と実際の遷移結果、画像の読み込み・Promise共有・失敗時の挙動、実ビルドの旧形式除外・古い出力拒否・素材不足を検査する。

素材100音声・18画像のバイト一致、保存・遷移モジュールの変更なし、既存の読み込み時点と再利用を確認する。実機やSafari/Firefoxでの検証は含まない。具体的な実行結果とPRプレビューはPR本文に記録する。
