# P1: 原本を保持した配信素材の軽量化

2026-10-12。P0の上に、声67本とBGM代替2本をAAC-LC、配信画像18枚をWebPへ変更。BGMのOGGと効果音MP3は無加工。原本WAV/PNG、生成入力・出典・ハッシュ記録は保つ。23本の未使用／旧版録音を配信から外す。原作・正解・状態遷移・音声キュー・タイムライン・無音処理・保存キー/versionを変更しない。

代表3本はWAV/AAC/Opusを機械比較し、AACを選択。代表画像は森・球・赤い箱を並べて視認。球・表情の重要な素材は品質95、他は85。縮小せずアルファは画素単位で維持する。主観的な聞き取り・実機音量は未確認の公開前項目。

単体98成功、原本照合2スキップ。新AAC全69本の実Web Audioデコード・数字4組の原本／派生連結比較はChromium 2成功。関連Chromium 7成功（GA、最新試行による取消し、実三箱→紙→枝→辞退・呼び直し→全問誤答→救出、救出の実音源）。全単体の原音ハッシュ・生成記録検査はWAV原本を引き続き照合し、派生は別にcheck:mediaで照合する。build/PagesのHTTP・MIME・Range・公開許可リストも成功。

配信総量と初回／プレイ中の実転送を区別し、条件固定の各3回の前後計測を [比較表](performance/COMPARISON.md)、全ファイルCSVと生データへ保存した。数値を実機やCDNの速度へ一般化しない。controlsMsは操作ボタンの表示で、絵の取得完了やTTIとは別。

Cloudflareのビルドではコミット済み派生をdistへコピーし、エンコーダやゲームのライブラリを追加しない。再変換だけFFmpeg/Pillowを使用する。未知の古いdistを黙って消さない既存検査を維持。
