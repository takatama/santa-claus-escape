## 起動と操作

既存の4190番が同じ試作を配信している場合はそのまま使います。停止していてポートが空いている場合のみ、Node.js 24以降で以下を実行します。4186番を使用・停止しません。

```powershell
cd 'C:\Users\takat\OneDrive\ドキュメント\ChatGPT\santa-clause-escape\illustrated-prototype'
npm start -- --port 4190
```

- 森の箱を触るか「箱を大きく見る」で調査します。
- 四輪の列を上へ回すと下の数字が中央に来ます。下へ回すと上の数字が中央に来ます。上下ドラッグ・↑↓・数字キー・左右の桁移動も使えます。
- 「この数字で試す」は錠のすぐ下にあり、最初から試せます。手がかりや資料の閲覧は解除条件ではありません。
- 「調べてみる」の1回目で山の絵、2回目でその横の「サガルマータ」、3回目で「その高さは、この端末が知っている」が現れます。雪は曲線に沿って徐々に取れ、周囲に不規則に残ります。自由なこすり操作はありません。
- 最後に「サガルマータについて調べる」を押すと、原作の資料を読み返せます。資料を開閉しても調査段階や錠は変わりません。
- この謎では原作時点の高さを使います。最新の測量値へ答えを変更していません。資料の数字は求めた場合にだけ表示します。
- 「森に戻る」やEscapeで数字と発見済みの手がかりを保持します。雪を払う途中で閉じた場合は、押した一段階を完了します。
- 解錠後は森でふたを上へ引きます。途中停止・逆戻し、ボタン・スライダー・キーでも操作できます。全開で「い」「よ」の紙を一度だけ得ます。
- 「最初に戻す」で雪・資料・数字0000・錠閉・ふた0%・紙0枚へ戻ります。

## 原作と素材

`prototype/full-scenario.js`と`prototype/reference/legacy-index.js`の日本語`blueBox1–4` / `sagarmatha` / 解錠判定 / 授与文字を照合しています。原文は[box-math.js](box-math.js)の`EXAM_CLUES`と`INFORMATION`に保持しています。答えや新しい謎、台詞、救出の進行を追加していません。

青い本体・ふた・山の絵は制作時に組み込みimage_genで用意し、[assets](assets/)に保存しました。制作プロンプトと参照元は[assets/PROMPTS.json](assets/PROMPTS.json)に記録しています。森・球・枝は既存素材を再利用します。正確な文字、数輪、雪は分離してコードで描き、画像の文字を解答に使いません。原画像は上書きしません。

作業は`illustrated-prototype`内です。既存ゲーム、paper-prototype、threejs-prototype、元の参照画像を変更しません。ゲーム実行時の生成AI・外部API・音声、サーバー機能、公開・デプロイは対象外です。
