# 初見の入口と、一手ずつ選ぶ操作 — 2026-10-07

利用者の「初見では使いづらい」に対し、どこで迷ったかを確認した。回答は「最初に何をすればよいか分からないこと」。桁の入力方法だけを変更する前に、最初の行動と、次の操作が出る順序を見直した。また、じゃんけんは絵を見ながら一手ずつ選ぶという指定を受け、四桁の汎用入力とは別の操作ラフを用意した。

## 赤い箱の入口

<http://127.0.0.1:4190/red-box/index.html>

- 開始は「赤い箱をタップして調べよう」と、押せる「箱を調べる」を表示。箱の印も虫眼鏡にした。
- 箱を調べる前には本文・数字欄・開箱ボタンを出さない。初回で原作の調査1の本文が現れ、以後は2→3→4へ進む。
- 「数字を合わせる」を選んだ後で数字窓と0〜9を表示。最初の桁を選択済みにし、次にする操作を示す。
- 「手がかりを読む」で戻っても入力した数字を保持する。
- 解錠した後に開箱の操作を出し、「ふたを上へ引いて、中をのぞこう」と案内する。
- 原作の既知の答えの経路を残すため、調査前から数字を合わせることもできる。調査したことにはしない。
- リセットでは調査前、本文/数字欄/開箱操作を隠した開始状態へ戻る。

原作の四段階の本文・正解・開箱条件は変更していない。最初に調べたことにする表示をやめ、最初の行動で本文を表示するようにした。森・球・箱の縮尺、ふたの幾何、ドラッグの可逆性は維持した。

## 絵を見て、一手ずつ選ぶ

<http://127.0.0.1:4190/storyboard/yellow-hands.html>

日本語の黄色い箱の手がかりを調べた後から始める、操作だけのラフ。完成した黄箱イラストやゲームの解錠処理は含めない。

箱の固定絵はグー→チョキ→パー→グー。一枚を大きく見せ、その下にグー/チョキ/パーの三つの手を置く。自分の手を選ぶと選択を表示し、同じ絵に留まる。「次の絵へ」で進む。前の絵に戻り、変更できる。最後は四つの絵と自分の四手を見返せる。

原作の「負けるが勝ち」「指の数があなたをみちびく」を見える場所に置いた。一手ごとの正誤、正解の手、数字への自動変換は出していない。数字の意味を考える謎を、操作補助が先に解いてしまわないため。英語原作の黄箱は別の数字謎なので、この日本語ラフをそのまま英語版へ転用する前提にはしない。

手の絵はSVGの操作確認用。森と球内サンタは既存素材を再利用し、絵柄と三つの選択肢が390×844で同時に見える。絵コンテの黄色調査2以降と、赤箱の関連リンクから開ける。

## 実ブラウザの確認

内蔵ブラウザの実クリック・タップ・キーで確認。DOM評価は読み取りだけで、ゲーム状態は書き換えていない。[確認値](red-box/qa/guided-results.json)。

| 項目 | 確認したこと |
| --- | --- |
| 赤箱の開始 | 本文と数字フォームはhidden、開箱操作はdisplay:none。最初の案内が見える |
| 最初の行動 | 箱のタップと「箱を調べる」で、調査1の原文が表示される |
| 数字への移行 | 明示操作の後だけフォームを表示。1桁目と数字選択が出て、フォーカスはBUTTON |
| 読み返し | 一桁だけ設定して本文へ戻り、3000を保持した |
| 解錠・発見 | 調査4→数字選択→確定→全開で二枚の文字へ到達。球と箱の配置は同値 |
| 既知の答え | 調査前の直接入力＋Enterで解錠。未調査のままで、勝手に調査済みにしない |
| 赤箱の幅 | 1280/390/320幅で横にはみ出さず、開始/入力の両状態を操作できる |
| 手の未選択 | 次へは無効。未到達の絵への移動も無効 |
| 一手の選択 | 選んでも1/4に留まる。次へ押下で2/4へ進む |
| 戻って変更 | 戻ると前の選択を保持。まとめから一手だけ変え、ほかの三手を保持 |
| 四手のまとめ | 四手がそろってから表示。正しい組合せでも別の組合せでも、局所の正誤や数字を出さない |
| 手のリセット | 四つとも未選択・1/4・次へ無効へ戻る |
| 手のキーボード | 手をEnterで選択し、次へEnterで進める |
| 手の画面幅 | 390/320/1280を確認。320幅はdocument305px、1280幅は1265pxで横にはみ出さない |
| 誤った操作領域 | 四手ナビのボタン間の空白をタップしても、次の絵へ進まない |
| JavaScript | 赤箱と手選択の検査タブで警告・エラー0件 |

`npm run check`：16 JavaScriptファイルの構文、62ローカル参照、20 HTML/CSS/JSファイルが合格。`npm test`：既存の状態・可逆性・幾何25群が合格。静的HTML/CSS/JSなので追加のビルドや依存インストールは不要。

## まだ分からないこと

今回確認したのは、入口を明示した表示と、手を一つずつ選べる動作。**初見の利用者が今度は迷わないか、じゃんけんとして楽しいかは、まだ利用者の再確認が必要。** 実装が動くことだけを使いやすさの証明にしない。

手を選ぶラフは調査後から始まる。調査→四手選択→本人が数字の意味を考える→錠を試す、という一連の接続は未実装。手のSVGは完成画風の素材ではなく、黄箱全体の絵の魅力もまだ評価していない。実端末の指・OSキーボード・読み上げの検査は未実施。

赤箱の数字窓とテンキーは前回の方式を維持し、今回は最初の入口と表示順を修正した。数字選択そのものも分かりにくければ、その観察をもとに次の変更を判断する。

実装は `illustrated-prototype` 内だけ。既存ゲーム、旧試作、参照画像、4186番プレビューは変更せず、4190番の既存静的サーバーで確認した。全編統合・新しい謎・音声・サーバー機能・公開は追加していない。一時の検査タブと表示幅設定を片付け、赤箱と手選択ラフを開始状態で残した。
