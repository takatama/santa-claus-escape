# まほう使いとの誘いと三つの遊び

接続した森から、発見→誘い→原作の三問→既存の救出場面へ進めます。問題・回答・台詞は `prototype/full-scenario.js` の原文を保持し、制作時の検証で照合します。実行時に元のゲームへ依存しません。全問誤答でも、まほう使いの答えを読んで三問を終えると救出へ進みます。新しい謎や回答はありません。

- 「今は遊ばない」でまほう使いは去り、サンタは球内に残ります。ひみつの言葉で呼び直すと、原作の再誘いに戻ります。
- 一問目と三問目は入力、二問目は原文の三択です。空入力は進みません。「わからない」も伝えられます。回答後に「続きを見る」を押して次へ進みます。
- 問題文の「10秒間」は原文の台詞です。強制タイマーはありません。音声は今回追加していません。
- 絵の下に文章と入力を置きます。長い台詞はページを縦にスクロールして読みます。会話中のサンタは全段階で球内です。
- 三問目の返答を読んで「続きを見る」を押したら、まほう使いの「うふふ。ああ楽しかった！」を約2秒表示し、既存の救出場面へ自動で進みます。「サンタのもとへ」で直ちに進むこともできます。解放の完了時に原作の結びの台詞を表示します。救出操作は既存の可逆な表現試作です。
- 終了済みの会話を見返す時は自動移動せず、手動の続行を残します。保存不可、別タブのやり直し・更新、ページを離れる操作では自動移動を止めます。[自動移動の確認記録](../qa/WITCH-RESCUE-TRANSITION.md)。
- 救出の途中の解放率はページ間で保存しません。会話の三問を終えた状態と回答履歴は保持します。

`?journey=1` の時だけ、専用のローカル保存で発見の開き具合、会話の段階、入力途中の答えと回答履歴を保持します。旧v1の紙・箱・言葉の保存を維持して追加項目を移行します。発見前の会話URL、三問終了前の救出URLは現在の段階へ戻します。森の「最初から」で全体を初期化します。別タブの古い質問・回答や再誘いのボタンが、新しい段階を上書きしないよう保存世代と会話の更新番号を照合します。

パラメータのない [独立プレビュー](http://127.0.0.1:4190/witch/index.html) は誘いから始まる、そのページ内だけの試作です。「最初に戻す」で誘いへ戻り、接続した進行は読み書きしません。再読み込みも初期化です。

新しい画像は生成せず、既存の森・球・枝・まほう使いを使います。実行時AI・API・音声・サーバー保存・公開は対象外です。4190の既存プレビューを再利用します。

構文・素材参照は `npm run check`、会話の原文・分岐・保存は `npm test`。実ブラウザで確認した範囲と未検証項目は [確認記録](qa/VERIFICATION.md) を参照してください。
