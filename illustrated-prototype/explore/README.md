# 三つの箱から、ひみつの言葉へ

[導入から接続した試作を開く](http://127.0.0.1:4190/intro/index.html) / [森を直接開く](http://127.0.0.1:4190/explore/index.html)

三つの箱を自由に調べ、実際に見つけた紙を並べ、ひみつの言葉から発見・誘い・原作の三問・救出へ進む接続試作です。既存の雪払い・四桁錠・ふた・六枚の紙を使います。サンタは救出を始めるまでスノーボール内にいます。[会話と保存の範囲](../witch/README.md)。

## 遊び方

- 箱で紙を見つけたら、画面下の大きな「ほかの箱を調べる」で森へ進めます。六枚揃うと「ひみつの言葉を作る」へ切り替わります。解錠だけではこの操作は出しません。合言葉の新しい正解時は発見へ自動で進みます。[解答後の誘導と確認](../qa/POST-SOLVE-NAVIGATION.md)。
- 森の三つの箱から好きな箱を選びます。箱の間も、森を経由しても移動できます。
- 数字、雪を払った段階、解除した錠、ふたの途中の開き具合は保存します。箱の調査を離れても、再読み込みしても続きから遊べます。雪払い中に離れた場合は、その段階を払い終えた状態で続けます。
- 紙はふたを十分に開いて見つけた時に取得します。錠の解除だけでは取得しません。ふたを閉じ直しても取得済みの紙は残ります。同じ箱を何度開けても紙は増えません。
- 「ひみつの言葉」の場面にはいつでも進めます。持っている紙だけが表示され、並べ方と入力途中の言葉も保存します。未取得の文字や、六枚がそろった時の原文を先に表示しません。
- 紙をまだ持っていなくても、言葉を知っていたら直接入力できます。成功しても未取得の紙や箱の解除を追加しません。
- 呼びかけに成功すると箱は森から消え、枝の向こうを見る入口になります。発見後は会話の続きへ戻れます。「今は遊ばない」の後は、ひみつの言葉でまほう使いを再び呼べます。
- 箱と紙の場面の上部は「森に戻る」です。全体をやり直す時は森の「最初から」を使います。
- 「最初から」は保存を初期化して原作の導入へ戻ります。「はじめのお話を読む」は現在の進行を保って導入だけ読み返します。[導入の操作と再開](../intro/README.md)。森の直接URLでは導入を必須にしません。

## 保存と独立試作

保存は同じブラウザのローカルストレージ、専用キー `santa-illustrated-journey-v1` のみを使用します。元のゲームや他の試作の保存は読み書きしません。外部通信やサーバーへの保存はありません。

森からは各場面のURLに `?journey=1` を付けて進みます。パラメータのない赤・青・黄と六枚の紙は引き続き独立した表現確認用です。独立場面で取得した紙や、六枚の紙の初期見本は接続した進行へ持ち込みません。

保存を使用できない場合は画面に表示します。この場合、ページをまたいで進行を保持できません。「最初から」はこの接続試作の保存だけを初期化します。リセットの保存に失敗した場合はページを移動せず、そのページ内で初期状態を表示します。別のタブに残った古い状態が、正常なリセット後の進行を復活させないよう保存世代を区別します。

## 起動と範囲

4190番の既存プレビューを再利用します。停止していて空いている場合のみ、`illustrated-prototype` で `npm start -- --port 4190` を実行します。4186番は使用・停止しません。

新しい謎・答え・物語の台詞・救出の進行は追加しません。森、球、枝、箱の絵は既存素材です。既存ゲーム、paper-prototype、threejs-prototype、参照画像、音声は変更しません。ゲーム実行時の生成AI・外部API・サーバー機能・公開・デプロイは対象外です。

`npm test` で保存と状態の整合性、`npm run check` で構文・ローカル参照を確認します。実ブラウザの結果と限界は [今回の確認記録](qa/VERIFICATION.md) に記録します。
