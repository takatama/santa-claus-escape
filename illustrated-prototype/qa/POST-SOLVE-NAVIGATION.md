# 解いた後の誘導と黄色の右手 — 2026-10-09

ユーザーの「解いた後、右上の戻るや画面下のリンクに気づかず迷う」という指摘に対応した現行版の記録です。過去の試作の機能確認と、今回の誘導変更の確認を分けます。

## 変更

- 黄色のパー：右手素材を描画時に反転して左手にしていたため、`paper.mirrored` を false に訂正。グーfalse、チョキtrueを維持し、手のひらを基準に揃えた大きさ・四つの順序・雪払い範囲は維持します。PNGは変更していません。
- 三箱：実際の紙取得後に、下端の固定帯へ二文字と大きな次操作を表示。接続モードの2/4枚は「ほかの箱を調べる」、6枚は「ひみつの言葉を作る」。紙を読む余裕を保つため、箱では自動移動しません。独立モードは従来の六枚の紙の独立試作へ進み、全編の取得履歴は作りません。
- 合言葉：入力と紙の並びの両方で、新しい正解を受け付けた時に成功を表示し、約1.1秒後に発見へ自動移動。発見済みなら最新の会話へ進みます。手動で直ちに進む主操作も同じ成功帯に残します。
- 成功済みの見返し：自動移動せず、目立つ次操作を残します。誤答・空欄でもその場に留まります。
- 発見：枝を開き終えた後、下端に大きな「まほう使いと話す」を表示。枝を操作する焦点を奪わず、逆戻しすると隠します。
- 救出：完成後の「サンタのお話を読む」で既存の結末本文へ移り、案内帯をしまいます。逆戻し・再完成で案内を再表示します。

原作の台詞・謎・正解・三問の正誤と救出の進行は変更しません。三問の返答は引き続き読んでから進みます。サンタは救出の前まで球内です。

## 保存と遷移

合言葉は保存を先に行い、その返却状態を確認してから成功を表示・遷移します。保存前に別タブのリセット世代を承認してしまう描画順序を修正しました。タイマー実行時も最新の保存と遷移先を確認します。pageshow・storage・pagehide・やり直しで自動移動を取り消します。

保存不可時は接続モードの自動移動と次リンクを止め、理由を表示します。箱の次操作もクリック前に最新の取得状態を確認し、共有リセット後の古い紙取得表示から進まないようにしています。
