# 雪を徐々に払う動き・錠直下の試行ボタン — 2026-10-08

[プレビュー](http://127.0.0.1:4190/red-box/index.html) ／ [操作](../README.md) ／ [ブラウザで読んだ値](2026-10-08-brushed/results.json)

## 修正

ユーザーの指摘を受け、四角い雪の面を一度に落とす表現を廃止。`snow-reveal.js`で曲線に沿った柔らかい消去跡を重ね、手で払うように少しずつ露出させる。文章は上の行を右へ、次に下の行を左へ、たぬきは短く往復、最後の文字は横へ払う。所要時間は順に1700 / 1900 / 1150ms。雪片は動いている位置から落ちる。

発見後も、紙の周囲、行間、絵の周りに元の雪の質感を残す。文字や絵に合わせた不規則な輪郭にし、文章の行間には小さな雪の粒も残す。画面比率に合わせて文字・絵と雪の消去跡を揃え、通常の森の箱にも同じ雪マスクを使う。

操作は「調べてみる」による文章二行→たぬき→下のラベルと先頭×の順を保持。任意の場所を自由にこする方式には戻していない。後のヒントが先に出ない境界を持たせた。動きを減らす設定では同じ一段階を即時表示する。

「この数字で試す」を錠の8px下に配置。錠プレートの外にある操作ボタンとして描き、紙とは重ねない。四つの数輪・プレート・ネジが継ぎ目より下にある構造は保持。ヒントを見る前にも試行・解除できる。

## 実ブラウザで確認

Codex内蔵ブラウザの別タブを使用し、既存タブのユーザーが遊んだ状態は保持した。1280×720と390×844で実際のクリック・ダブルクリック・ドラッグ・キーを使用。評価用JavaScriptはDOMと寸法の読み取りだけで、内部状態を注入していない。4190の既存静的サーバーを再利用し、4186には操作していない。

| 確認 | 結果 |
| --- | --- |
| 初期 | 0000・段階0。全文・たぬきの顔・×は未表示 |
| 払う途中 | 文章が横へ少しずつ現れる。次の行や後段ヒントはまだ雪の下 |
| 順番 | 両幅で0→1→2→3。読み返しの内容にも後段ヒントを先出ししない |
| 残る雪 | 完了後も周囲・行間に雪が残り、露出した境界は不規則。二行・絵・ラベルと×を読み取れる |
| 試行ボタン | 錠の下8px、44px高。紙との間は約4.52px。両幅で重なりなし |
| 移動後のダイアル | 上タップ・上ドラッグで0000→1000、下タップ・下ドラッグで1000→0000。↑キーでも0000→1000 |
| ヒント前の試行 | 段階0・0000で誤答表示。段階0・3138で解除、ふた0%・紙0枚を保持 |
| 連打 | ダブルクリックで段階1だけ進む。演出中は調査ボタン無効 |
| 途中で閉じる | 押した一段階を完了して保持。再開で段階1・0000 |
| やり直し | 数字0000、段階0、錠閉、ふた0%、紙0枚へ戻る。演出中に閉じてリセットしても古い演出が後から進まない |
| サンタ | 通常の森の画像と`santaContained=true`で球内維持を確認 |
| 横方向 | 通常幅1265px≤1280px、390幅375px≤390px。ダイアログ内も横のはみ出しなし |
| JavaScript | 警告・エラーログ0件 |

通常幅では本文を縦にスクロールできる。調査ボタンを押した後に箱の上端が画面外へ出る場合があるが、操作する錠、試行、対象のヒント、戻るは見える。これはページの横スクロールとは別に確認した。

別担当が通常幅3枚とモバイル5枚を実際に見て、順序、読みやすさ、雪の輪郭、試行ボタンの重なりを確認した。
