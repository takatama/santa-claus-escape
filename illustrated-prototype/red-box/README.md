## 操作

- 森の箱のタップ、絵にフォーカスしてEnter/Space、または「箱を大きく見る」で調査表示を開きます。
- 錠には上・中央・下の数字が見えます。上をタップすると数字列が上へ回り、下にあった数字が中央へ来ます。上9・中央0・下1なら上タップで1、下タップで9になります。
- 上下に引くと数字列が指の移動に追従します。一行分動くごとに数字が確定し、離すと未確定の端数だけ中央へ戻ります。逆方向にも動かせます。
- 中央にフォーカスして↑/↓で同じ方向へ回転、数字キーで直接入力、←/→で桁を移動できます。桁は自動で次へ移りません。
- 「この数字で試す」は錠のすぐ下にあります。最初から押せ、手がかりの閲覧は解除の条件ではありません。
- 「調べてみる」の1回目で「サンタ、イタチ」「サンタ、ハタチ」の二行、2回目でたぬきの絵、3回目で絵の下の「たぬき」と先頭「た」の×が現れます。任意の場所をこする操作はありません。
- ボタンを押すと、手で払うような曲線の動きで雪が少しずつ取れます。文章は上の行から下の行へ、絵は短い往復、最後の文字は横へ払います。現れた後も、行間や周囲に不規則な雪が残ります。
- 雪が落ちる間は調査ボタンを無効にし、連打で段階を飛ばしません。動きを減らす設定では同じ順序ですぐに表示します。
- 「見えた文字を読む」には、その時点で発見した内容だけが入ります。解法の説明は追加しません。
- 「森に戻る」やEscapeで調査を閉じても、数字と発見した段階は残ります。雪が落ちる途中で閉じた場合は、押した一段階を完了して保持します。
- 解錠だけではふたは開きません。森に戻ってふたを上へ引き、下へ引いて戻せます。離すと途中で止まります。ボタン、スライダー、絵の↑↓/←→、Home/Endでも操作できます。
- 「最初に戻す」で数字0000、初期の雪、錠閉、ふた閉、紙0枚へ戻ります。
