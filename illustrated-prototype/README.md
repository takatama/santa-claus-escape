# サンタの脱出 — 絵の中を探索する動く絵本

原作の導入から、雪の森の三箱・六枚の紙・ひみつの言葉・まほう使いとの三問・サンタの救出と結末までを接続した、独立した絵本風のブラウザ試作です。[最初から遊ぶ入口](intro/index.html)を開きます。生成イラストの紙と絵の具の質感、深い青の雪の森、暖かい金色を使い、固定視点の絵の中で手がかりと操作を探します。

通常の進行は専用のローカル保存で保持し、原作の台詞・謎・答え・全問誤答でも救出へ進む流れを保ちます。サンタは救出前まで球内です。ページごとの独立プレビューと絵コンテも表現の確認用に残しています。ルートの `index.html` は従来の発見場面だけの独立試作で、全編の入口は `intro/index.html` です。

一通りの進行は実装・検査済みですが、スマホ実機や初見の親子での体験は未検証です。今回のPRの範囲と再現できる検査は [PR確認記録](qa/PR-VERIFICATION.md) にまとめます。

## 操作と描画

枝の丸い矢印を外へドラッグすると開き、内へドラッグすると戻ります。左右どちらからでも操作できます。離すと停止し、再び触った位置から続けられます。絵のタップ、開く/戻すボタンは20%ずつ、絵にフォーカスした矢印キーは5%ずつ動かします。Homeで開始、Endで完成、Enter/Spaceでも20%開けます。スライダーは任意の位置に動かせます。

Canvas 2Dで生成素材を合成。枝は根元を固定した曲面メッシュに沿って変形し、右側から杖の光、左側から顔と手が見えるように開き方を調整しました。枝の開き・人物の照明・光・球内の頭と手の小さな反応は、すべて同じ0〜1の進捗の関数です。カメラや完成絵全体を動かす演出はありません。開閉中の自動演出はタップ/ボタンの440ms補間のみで、ドラッグには慣性・完了への吸着を付けていません。

生成素材と完全な制作プロンプトは [assets/PROMPTS.json](assets/PROMPTS.json)、背景仕上げの指示は [assets/FOREST-EDIT.md](assets/FOREST-EDIT.md)、脚の修正指示は [assets/WIZARD-FEET-EDIT.md](assets/WIZARD-FEET-EDIT.md)。組み込みimage_genを使い、指定の三枚を画風・人物の参照として制作しました。現在の採用素材はforest-clean.png、wizard-feet-v2.png、globe.png、branch.pngです。wizard.pngは修正前として保存しています。透明な余白は読み込み時にメモリ上で除きます。元の参照画像は変更していません。

人物の輪郭を突然切り替える方式は使っていません。まほう使いは同じ手を差し出したポーズに光が当たり、枝の奥から見えてきます。サンタの反応は頭とミトンの局所的な変形であり、別の驚き顔・大きな振り向きポーズまでは制作していません。

## ブラウザで確認する項目

- 開始・途中・完成が一枚の絵として成立する。
- ドラッグを離すと途中で止まり、逆方向へ動かすと元へ戻る。
- 金色の光、杖、人物が表示境界で急に跳ね出さない。
- サンタが全状態で球内に留まり、発見に反応する。
- タップ、キーボード、最初に戻す操作で同じ発見に到達できる。
- 通常幅と390×844で操作でき、横にはみ出さない。
- JavaScriptエラーがない。

機能の動作確認と、絵の魅力や「もっと奥を見たい」という体験の評価は分けて記録します。画面幅の確認は実機のタッチ操作の証明ではありません。スマホ実機の指操作、初見の使いやすさ、親子での体験は未検証です。
