# サンタの声から、三つの箱へ

[導入から遊ぶ](http://127.0.0.1:4190/intro/index.html) / [進行を保って導入を読み返す](http://127.0.0.1:4190/intro/index.html?journey=1&replay=1)

原作の「声が聞こえる→サンタが事情を話す→助けることを選ぶ→三つの箱とひみつの言葉の説明」を、既存の雪の森とスノーボールでつなぐ入口です。本文は `prototype/scenario.js` と `prototype/full-scenario.js` の intro/help をそのまま使い、新しい台詞・謎・答え・断る分岐は追加しません。

## 操作と続き

初めてこの入口を開くと、導入から始まります。「声を聞く」「続きを見る」「サンタを助ける」「三つの箱を調べる」の順に進み、赤・青・黄を自由な順で探索できます。森と球の配置・縮尺は導入から探索まで共通です。箱は説明が終わって探索へ進んだ時に表示します。サンタは救出の操作を始めるまで球内にいます。

台詞と操作は絵の下に置き、長い本文は縦にスクロールして読めます。操作はボタンのタップ・クリック・キーボードで行います。新しい音声・イラストは制作していません。

導入途中の段階は既存の専用保存に保持し、再読み込みしても同じ段階から続けられます。導入を終えた保存では、箱の探索、まほう使いの発見、会話のいずれかへ戻ります。救出の途中の描画進捗は引き続き別ページへ持ち越しません。

森の「はじめのお話を読む」と `replay=1` の入口は、保存へ書き込まず導入だけ読み返します。上部の「続きに戻る」または読み終えた後の「続きから遊ぶ」で、現在の探索・発見・会話へ戻ります。

森の「最初から」は接続試作の保存だけを初期化し、導入へ戻ります。保存に失敗した場合は同じ森のページ内で初期状態と保存不可の表示を出します。この場合、ページをまたいで進行を保持できません。

## 既存の入口と保存

全編の初回入口はこの intro ページです。既存の [森の探索URL](../explore/index.html) は直接探索するショートカットとして残します。箱や紙の独立URLも維持し、本文や手がかりの閲覧を解答の必須条件にしません。

`?journey=1` を省いた intro URL は接続モードに揃えます。専用キーは従来どおり `santa-illustrated-journey-v1` です。旧保存に導入の段階がなくても、箱の数字・雪払い・紙・入力・発見・会話の進行があれば導入完了として復元します。全く進めていない旧保存では導入から始めます。

導入の更新は現在の段階と改訂番号を照合します。別のページでゲームを進めた後に、古い導入操作が進行を戻すことを防ぎます。元のゲームや他の試作の保存は使用しません。

## 起動・確認・範囲

4190番の既存静的サーバーを再利用します。4186番は使用・停止しません。起動手順は [全体README](../README.md)、保存と箱の操作は [探索README](../explore/README.md)、今回の証拠と限界は [導入の確認記録](qa/VERIFICATION.md) を参照してください。

`npm test` は導入の原文一致、状態の順序、復元、旧保存の移行、古い操作の拒否を含みます。`npm run check` は構文とローカル参照・外部通信のない構成を検査します。ブラウザの幅確認はスマホ実機の操作や初見の理解の証明ではありません。

変更は illustrated-prototype 内のみです。既存ゲーム、paper-prototype、threejs-prototype、元の参照画像、音声は変更しません。実行時の生成AI・外部API・サーバー機能・公開・デプロイは対象外です。
