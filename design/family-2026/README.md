# 親子でひらく「サンタの脱出」― 調査と設計（2026年版）

PR #1（絵本風試作）を調べ、「大人がぜひ子どもと一緒に楽しみたいと思えるアプリ」にするための調査と設計をまとめたフォルダです。2026-10-09〜10 に作成しました。**実装はしていません。子どもを含む試遊も、まだ一度もしていません。**

## 結論

1. **作るもの**：スノードームに閉じ込められたサンタを、親子が**4つの章**（1章10〜20分が目安）で助ける、声と絵の動く絵本。続けて、**わが家のイブの夜**の読み返しと、**25日の朝の手紙**。作業名は「サンタの脱出 ― 親子でひらく よっつの夜」。
2. **大人が一緒に遊びたくなる理由**【推定】：原作は「かまってもらえなかった、さびしいまほう使いと遊ぶと、サンタが自由になる」話で、親子で遊ぶこと自体が物語の答えになっている。大人には、語り（原作では端末そのものの「私」）を読む役、子どもに「ちがうよ、ソリだよ！」と正される「ないしょの いたずら」、イブの夜に最後の一行「クリスマスの夜を楽しみにしていてくれ」を自分の声で言う役がある。何もしなくても最後まで遊べる。
3. **推奨**：方向は「標準パック」（原作の台詞・謎・答えは1字も変えず、CI で検査する）。11/27 の凍結で約束するのは「確実版」。台詞を足す「踏み込みパック」は2027年に回す。
4. **技術の約束は守る**：実行時 AI・マイク・アカウント・解析・広告・通知なし。静的配信の1ページ PWA。
5. **PR #1 はマージしない**：絵17枚、描画の純関数、四桁錠などの部品とテストを新しいアプリへ移す。理由と閉じるときの文面案は設計書 §16。
6. **日程は厳しい**【推定】：確実版の作業量は約40〜54人日で、10/12〜11/27 の平日は32日。律速はオーナーの判断と確認の時間（約46〜64時間）。届かない場合の公開を 12/4 にする予備案を先に決めておく。

## 7つの案

AI が7つの立場（保護者、発達心理、ゲームデザイナー、実装責任者、オーナーの価値観、子ども、マーケター）を演じてつけた点です。**実際の人の評価ではありません。**

| 案 | 中身 | 総合（中央値） | 強み | 弱み |
|---|---|---|---|---|
| 案3 よっつの夜 | 4つの夜に分け、イブと25日の朝へつなぐ | 8 | 情緒の記憶と忠実さ。評価が最もそろった | 遊びの中身は原作のまま |
| 案2 サンタの無線機 | 大人が自分のスマホでサンタの声とひみつ指令を持つ | 7 | 大人の楽しさと会話 | 2台目と QR、親がスマホを見る |
| 案4 おうちの雪の森キット | 印刷した箱を家に隠して宝探し | 6.5 | 子どもの喜び | 印刷と準備の重さ |
| 案5 まほう使いと あそぶ夜 | 後半を声と体の遊びにし、仲直りまで描く | 6.5 | 情緒の山場 | 台詞を約45行足す |
| 案1 声と絵の動く絵本 | PR #1 の絵に既存の声を統合 | 6 | 忠実さと実現性 | 大人の役が薄い |
| 案6 こんどは きみが まほう使い | 子どもが謎を作って大人を閉じ込める | 6 | 差別化 | 追加の遊び・台詞・共有 |
| 案7 よるのクリスマスラジオ | 画面を伏せて声だけで遊ぶ | 5 | 画面時間が最少 | 絵と手触りを捨てる |

推奨の設計は、案3 の時間の骨格に案1 の忠実な土台を敷き、案2 の大人の役を1台に縮め、案5 のうち台詞を足さない儀式を載せたものです。詳しくは [CONCEPT-COMPARISON.md](CONCEPT-COMPARISON.md) の §6。

## 作り方と、読むときの注意

- 調査：リポジトリと PR #1 を読む6本、外部の調査4本（共遊の研究、ベンチマーク、日本の家庭、技術）、実ブラウザでの通しプレイ1本を、統合ブリーフにまとめた。
- 設計：7つの切り口で独立に案を作り、7つの立場で比べて採点し、上位3案にプレモーテムと家族プレイの机上の想定をかけ、統合した設計書を4つの観点（完全性、オーナーの価値観と原作への忠実さ、実現性と日程、保護者の読みやすさ）で批評して改訂した。
- 文書の多くは AI エージェントが書いたもので、【事実】【推定】【要判断】を書き分けている。点数と机上の想定は判断の材料で、試遊の代わりにはならない。設計書 §13 の試遊で一つずつ確かめる前提で読んでほしい。
- 文書中の「リポジトリ、git の状態、GitHub は変更していない」は、各文書を作成した時点の記述。
