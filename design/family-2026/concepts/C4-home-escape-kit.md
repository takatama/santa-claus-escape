## 1. 名前／キャッチコピー／約束

- **名前**：サンタの脱出「おうちの雪の森キット」
- **キャッチコピー**：「みっつの はこを かくしたら、うちの なかが サンタを たすける ゆきの もりに なる。」
- **この案の約束（3行）**
  1. 大人の準備は**1回だけ・10分以内**（A4 を2枚印刷して、3か所に隠す）。毎晩の仕込みはない。
  2. 画面は、テーブルに置いた**スノードーム**。受け持つのは「声」と「錠」だけ。遊びの大半は、家の中で家族の足と手と声が担う。
  3. 原作の物語・台詞・謎は変えない。物語に欠けていた「だいすきだよ」の返事は、**25日の朝に大人が紙で返す**。

## 2. 誰が・いつ・どこで・何分・どの端末で

**基本の形**【推定】：端末は1台（親のスマホかタブレット）。テーブルかツリーの下に立てて置き、「ベースキャンプ」にする。子どもは家の中を探して、手がかりを持って戻ってくる。

**時間の構成**：「2幕＋朝」を標準にする。原作の分岐「今は遊ばない」（`prototype/full-scenario.js:31`）を幕間に使う。
- 第1幕：40分前後。箱を探す → 三つの箱を開ける → 六文字 → だいすきだよ → まほう使いが現れる →「今は遊ばない」
- 幕間：数時間〜数日。六文字は冷蔵庫に貼っておく
- 第2幕：15〜20分。合言葉で呼ぶ → 三つの遊び → 救出
- 25日の朝：1分。枕元に「サンタの へんじ」

**画面を見る時間の目標**【推定・要検証】：第1幕の4分の1以下（40分のうち10分以下）。

| | 家族A：共働きのマンション（2幕で遊ぶ） | 家族B：祖父母の家に集まる（1回で通す） |
|---|---|---|
| 人 | 父39・母37、ゆい6歳（年長）、そう3歳 | 祖父68・祖母66・母37、はると8歳（小2）、めい5歳（年中）、いとこのりく11歳（小5） |

| いつ | 第1幕：**12/19（土）16時**、ケーキの前に40分。第2幕：**12/24（木）19時半**、夕食の後に15分。**12/25（金）の朝**にへんじ | **12/20（日）14時**、通しで50〜60分。休憩はおやつ |

**2026年の暦**：イブは平日の木曜。2幕に分けると、**第2幕の救出がイブの夜に重なる**ように組める。結末の「クリスマスの夜を楽しみにしていてくれ」が、まさにその夜に響く。

**家族C（拡張）**：家のクリスマス会。子ども4〜9人が赤・青・黄の3チームに分かれる（§7）。

**帰省について**【推定】：年末年始の帰省はクリスマスの後なので、物語の時期とずれる。祖父母を巻き込む場は、12月の週末の訪問か、離れた祖父母とのビデオ通話（§3）にする。

**大人が「見守る人」ではなく「楽しむ参加者」になる理由**【推定、根拠は §5 P4〜P7、08 の型E】
1. **仕掛ける喜び**：自分が選んだ隠し場所で子どもが叫ぶ顔を見られる。日本の親の83.7%が何らかのサプライズ演出をしている（09）。この欲求を、10分で満たせる形にする。
2. **演じる役がある**：近さを伝える「ゆき／とけた」の声。黄色の「箱の手」として、わざと0250で失敗する。シカ10回では大人も引っかかる側になる。
3. **代わりがきかない**：審判、問いかけ、ヒントの手帳は、端末ではなく人が持つ。祖父母はヒントの手帳を持つ（離れていれば**ビデオ通話で「おばあちゃんに きく」**。Chicory の「親に電話してヒント」の型）。
4. **最後の一言を大人が書く**：25日の朝の「へんじ」は、アプリではなく大人の手で書く言葉にする。

## 5. 4つの山場の設計

**① だいすきだよ（3回訪れる）**

1回目（第1幕・発見）
- **紙を手で並べる。画面には入力欄を出さない。**
- 判定は大人がする（台本：「ならんだら、こえに だして いってみよう」）。
- 子どもが言い、大人が言い返す。「言い返す」は大人の台本にだけ書く（P13）。
- 最後に全員がドームに手を置く。3秒の長押しで、誰の指でもよい。成功を灰色で表示しない。
- **6人いれば「にんげん あいことば」**：一人1枚ずつ持って並び、声をそろえる。祖父母がいる家やクリスマス会で強い【推定】。

2回目（第2幕・呼び戻し）
- 冷蔵庫から六文字を持ってきて、家族でドームに「よびかける」。
- 原作の「この端末によびかけてくれれば」（`scenario.js:14`）が、声のまま戻る。

3回目（25日の朝）
- 枕元に置いた六文字の横に、**サンタのへんじ**がある。原作で誰も言い返さない問題（W2）を、**アプリの台詞を変えずに**、紙の上で大人が埋める。
- へんじの文面は2案から選ぶ【要判断】。
  - (a) 「わしも だいすきだよ」と印刷した札：サンタの新しい台詞になる。
  - (b) 金の枠だけの白い札：大人が自分の言葉で書く。
- **筆跡で正体に気づかれる例がある**（09）。(b) では、印刷の字か、ひらがなのスタンプを勧める。

**② シカ10回（家じゅうで）**
- まほう使い（Leda）が「せーの」と言い、**全員が立って、両手で角を作る**。
- 原作の10回の音声（`ja-leda-question-deer-ten-times`。PR #1 の `spoken`）に合わせて、画面のシカの足あとが10個灯る。
- 「サンタが乗ってくるのは？」には全員で叫ぶ。大人が［ソリ］［トナカイ］［そのほか］を押すと、原作の返事が鳴る（`…-right`／`…-wrong`。「トナカイ、じゃなくて、ソリだよね」）。
- **祖父母も父も引っかかる側になる**。子どもが大人の失敗を見て笑う【推定】。
- マイクは使わない。音量で拍子を数える案は採らない（§9）。

**③ 救出（家に「からっぽの球」が残る）**
- 原作どおり、救出の前にサンタは球を出ない（C10）。光を引く操作は PR #1 の手触りを移す。
- 救出の後は、**アプリを開いても空の球だけが出る**。サンタは家を出て仕事をしている、という後日談を、新しい台詞なしで絵1枚（既存の `empty-globe.png`）で伝える。

**④ 現実のクリスマスとの接続**
- **六文字は家に残る**：幕間は冷蔵庫、イブの夜は枕元かツリーの下、25日の朝は「へんじ」の横。
- **カードは記念になる**：とびらカードと封印をやぶった封筒は、翌年までとっておける。
- **子どもへの通知はしない。いつ遊ぶかは大人が決める**（P15）。

## 7. 年齢への対応・読み・ヒントと詰まり

**年齢**
- **5〜7歳（中心）**：見つける、とびらを開ける、数字を鉛筆で書く、ダイヤルを回す、並べる、言う。
- **3〜4歳**：**宝探しの主役**。隠れんぼ型の発見は、謎を解けない年齢でも手柄になる【推定】。封印をやぶる、紙を運ぶ、シカの角も担う。
- **8〜9歳**：赤と黄を自力で解き、年下に読み聞かせる。むずかしい版では、カードの裏に「封筒は別の場所にある」という場所の謎を足す（12月の追加。新しい文なので承認が要る）。
- **10〜12歳**：サンタの助手になり、隠す側に回る。これは**大人の準備の負担を減らす仕掛けでもある**。
- **きょうだい**：箱を1人1色に分けるか、「見つける係」と「解く係」に分ける。

**クリスマス会（家族Cの形）**
- 3チームが1色ずつ受け持つ。最後に六文字を1つのテーブルで合わせる。
- **順位・時間・速さは画面に出さない。球は待つだけ**。
- 一番むずかしい黄色は、大人か年長の子がいるチームにする。
- 人数の上限の目安は9人【推定】。

**読み**
- カードは、ひらがなの分かち書き。カタカナにはひらがなのルビを付ける（謎は「音」なのでカタカナは残す）。
- 全部の段に原作の語りの声があり、球に頼めば読んでくれる（ビート7）。
- 大人の手帳は漢字かな交じりで、読み聞かせの台本を兼ねる。
- 自由なかな入力はどこにもない。入力はダイヤルの数字と、大人の判定ボタンだけ。

**ヒントと詰まりへの対処**（どの段も任意。順位は付けない）

| 詰まり | 1段目 | 2段目 | 3段目 |
|---|---|---|---|
| 見つからない | 大人の「ゆきが ふってきた／とけてきた」 | 球の「サンタの けはい」：準備で選んだ隠し場所のマーク（冷蔵庫、本棚など8種）を絵だけで示す | 大人が一緒に探す |
| 謎が解けない | 球で、その段の原作の語りを聞き直す | 手帳の問いかけ（A4）。離れた祖父母にビデオ通話できく | 手帳の折り返しの下の答え |
| 黄色の0250 | 原作の誤りの声。原作の隠れたヒントは原作どおりに残す（言い回しの問題 C-10 があるので、格上げしない） | 大人が「箱の手」を出し、子どもが負ける手を出して指を数える | 同上 |
| 紙をなくした・破れた | 保護者ゲートの奥で、カードと六文字を画面に出せる | もう一度印刷する | ― |
| 疲れた・泣いた | 「今は遊ばない」でいつでも幕間にできる。球は待つ | ― | ― |

## 9. 技術構成（ブリーフ §8 との整合）

**ブリーフ §8 と同じにするもの**
- PWA を静的に配信する（Cloudflare Pages）。素の ES モジュールで、依存はゼロ。1ページ構成。
- AudioContext は1つ。台詞は AAC のスプライト。消音スイッチの対策も同じ。
- 保存は localStorage に小さな状態だけ。区画ごとに寛容に復元する。

**この案で軽くなるもの**【推定】
- 画面は球、錠、まほう使いの登場、救出の4つだけ。森を歩き回る描画が要らない。
- 自作の WebGL2 層は必須ではない。DOM と Canvas 2D で足り、メッシュが要るのは救出だけ（分割を 4×6 に減らす予備案で足りる見込み）。
- ブリーフの工程 W2〜3 の描画の作業は、半分以下に減らせる見込み。

**縦と横**
- 球は丸く、中央に置く構図なので、スマホの縦置きでもタブレットの横置きでも同じ絵で成り立つ。
- 縦長の背景がないという問題（C-20）を避けられる。

**ねむるドーム**
- 触られないまま30秒たつと UI を消し、球を暗くする（画面の明るさは変えず、黒い層を重ねる）。
- 画面が自動で消えないよう Screen Wake Lock を使う。iOS のホーム画面アプリで効くかは**実機で確かめる必要がある**【要確認】。効かない場合は、準備画面で自動ロックの延長を案内するだけにとどめる。

**印刷**
- PDF は、ビルド時にヘッドレスのブラウザで作る静的なファイル。サイトに同梱して precache する。
- 個人データは入れない：呼び名は使わず、へんじは手書き。
- 日本語フォントは、OFL などの埋め込みできるものを選ぶ【要確認：ライセンス】。
- 印刷用 CSS の `print.html` も用意する。

**再開**
- 幕間が数日に及んでも、**合言葉そのものが再開の鍵**になる（原作の直行経路）。
- iOS Safari は7日間使われないと保存データを消すが、この仕組みならその影響を受けない。

**L4 に触れる発想は、すべて採らない（別枠の案として示すだけ）**

| 発想 | 判断 | 守ったままの代替 |
|---|---|---|
| マイクの音量でシカ10回を数える | 不採用 | 足あとは録音の時刻に合わせて灯る |
| カメラでカードを読む・QR で進行を変える | 不採用（10 §6.2） | 数字はカードに印刷してあり、子どもがダイヤルで入れる |
| コンビニのネットプリントの予約番号を配る | **別枠・要承認**（外部サービスへの登録と有効期限の管理が要る【要調査】） | 親が自分で PDF をコンビニの印刷にかける |

キットの表紙の QR は、アプリのトップを開くだけにする。追跡用のパラメーターは付けない。

## 12. この案の正直な弱点と、あえてやらないこと

**弱点**
- **印刷という壁**：家のプリンターの保有率を確かめていない。印刷しない家では宝探しが消えて、普通の絵本ゲームに落ちる。
- **PR #1 の一番の魅力を捨てる**：雪をこする、枝をかき分ける、ふたを開ける、という画面の上の手触りの多くが、紙に置き換わる。オーナーが2日で7版作り直した赤い箱の操作も、錠のほかは使わない。
- **寝る前の遊びではない**：走り回るので、毎晩15〜20分ずつ読む章立ての案とは用途が違う。平日の夜には向かない。
- **一度きりになりやすい**：もう一度遊ぶには隠し直しが要る。答えが同じでは2回目が弱い（2年目の別カードは12月以降）。
- **判定は人がする**：機械は「言えた」かどうかを知らない。大人がいないと成り立たない。一人で遊べる時間はほぼない。
- **紙はなくなる**：六文字の紛失は退避で補えるが、魔法は少し損なわれる。
- **森の絵の見せ場が減る**：家が森の代わりになるので、PR #1 の美しい森の絵は球の背景と札にしか残らない。

**あえてやらないこと**
- 毎晩の仕込み、アドベントの毎日の窓（Elf の型）。
- 呼び名や写真をアプリに入れる、名前入りの PDF をアプリで作る（へんじは手書き）。
- QR やカメラで進行を変える、マイク、AR、位置や動きのセンサー。
- 宝探しのタイム、チームの順位、星やスコア。
- SNS に共有する機能、仕掛けを見せ合う導線（SNS で競い合う燃え尽きを避ける）。
- 原作の台詞を黙って足すこと（すべて A1〜A11 で承認を求める）。
