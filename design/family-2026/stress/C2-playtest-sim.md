# C2「こちらサンタ、どうぞ。」家族プレイの模擬テスト（4家族）

- 作成 2026-10-10。対象：`design/family-2026/concepts/C2-santa-radio.md`（以下 C2）。根拠：ブリーフ §2.2・§5・§7・§10.3、01 §6.1（区間ごとの所要時間）、11（答えを知る大人の通しで約10分）
- **これは想像による模擬で、実データではない。** 親子での試遊はまだ0回【事実】。以下の時刻・発話・点数・割合はすべて【推定】。名前は架空
- 前提（C2 §10 の 11/27 MVP で遊ぶ）
  - 「流す」（録音のサンタ）はなし。役の交代と、2台目の無線機の役別表示もなし（どちらも後回し）。年齢ごとの設定は残っている
  - 1台の家は「おとなのひきだし」（中央の画面の隅を3秒長押し）。中央の画面はスマホ縦を作り込まない（C2 §12）
  - まほう使い（Leda）と語り手（Sulafat）の録音は使える前提。Gemini の18歳条項の確認が取れなかった場合の悪化は、各家族の最後に1行で書く
  - 無線機のカードは C2 §4 の並び（第1夜＝箱1つ、第2夜＝残りの箱、第3夜＝六文字〜救出）

## 1. 家族(a) 5歳＋疲れた父／平日20時／父の iPhone 1台を縦持ち

12/2（水）。父（40）は19:40に帰宅。年長のゆい（5歳11か月。ひらがなは読める、カタカナは半分）。母は2歳の弟と風呂。端末は父の iPhone だけ。就寝は21:00。

| 時刻 | 起きること【推定】 |
|---|---|
| 19:58〜20:00 | 表紙で「無線機でいっしょに」を選ぶと QR が出る。読む2台目がない。「1台で遊ぶ」の入口を探して約1分（C2 は1台の入口を表紙に書いていない）。ゆい「はやく」 |
| 20:00〜20:02 | 心得3行と夜の分け方を、ゆいを待たせて読む。テスト受信「ザザッ…聞こえるか？」は1台では意味がない |
| 20:02 | 縦持ちなので、森の絵は画面の中央に細い帯で出る。父が横に倒す。最初の会話が「向き」になる |
| 20:03 | 救難の声。父は隅を3秒押してひきだしを開き、台詞を棒読み。ゆい「パパ、へんなこえ！」と笑う。**魔法①** 5歳は漢字かな交じりの台本を読めないので、秘密は守られる |
| 20:04〜05 | 「はい」→箱。台詞のたびにひきだしを開け閉めする。ゆい「あか！」。父は「めんどくさいな」と感じる |
| 20:06 | 雪払い。父「何て書いてある？ どうぞ」。ゆいはカタカナが読めない。文字にさわって語り手の声を聞き、まねして「サンタ、イタチ…どうぞ！」。**魔法②** 「どうぞ」が気に入り、以後どの発言にも付ける。作中の言い方が、操作の会話を物語の会話に変える |
| 20:07 | 雪払いの途中で、会社のチャットの通知が画面上部に出る。父が一瞬読む。ゆい「パパ見て！」。**大人の離脱1回**。中央の画面が父の私物なので、通知が割り込む |
| 20:08〜12 | 30秒の沈黙→ひきだしで、といかけ→2分でヒント①→②「サンタから"タ"をとると？」。ゆい「サン！」…「イチ！」。**魔法③** ハタチ→ハチは父が誘導する。「ハタチって何歳？」の指令は5歳には通じない |
| 20:13 | ダイヤル。小さな画面のうえ、回す向きが直感と逆（ブリーフ C-22）で、ゆいは2回回しすぎる。父「貸して」。ゆい「ゆいがやるの！」で**半泣き** |
| 20:15 | カチャ！ ふたを上へ引くと「す」「だ」の紙。「やったー」 |
| 20:16〜18 | 「無線を切る」カード。ゆいは「こちらゆい、きょうはここまで。どうぞ！」を3回言う。**魔法④** 自分の言葉で夜を閉じられる。「もう1回！」と言うが、歯みがきへ |

- **詰まる点**
  - 1台用の入口が見つからない
  - ひきだしの往復が1夜に約8回
  - ダイヤル
  - 赤い箱の「タを抜く」は、5歳だとヒント②まで要る（ブリーフ §2.2「声ありで6〜7歳」と合う）
- **大人の退屈・離脱**：準備の文を読む時間とひきだしの往復。疲れた父には「演じる」より「台本を探す」負担が大きい。通知で1回
- **泣き・飽き**
  - ダイヤルを取り上げられたとき
  - 第3夜（12/6）の「スマホを伏せて言う」は、1台では救出の絵ごと伏せることになり、成り立たない
- **だいすきだよ（第3夜）**：赤い封筒はひきだしの中にある。ゆいが言った瞬間に、父は封筒を見られない。「言えたね」とほめるだけで言い返さない見込みが、半々ほど
- **所要時間**：準備2.5分＋本編15分で約18分。詰まれば22分。第3夜は約14分
- **声が使えない場合**：カタカナの手がかりも父が読むことになり、ひきだしの往復がさらに増える
