# 実プレイ所見（メインセッションが実ブラウザで通しプレイ）

日時: 2026-10-09 / 環境: 内蔵ブラウザ、1180×820（タブレット横相当）、PR #1 ブランチ `illustrated-prototype/intro/index.html?journey=1` から開始。比較のため main の `prototype/`（声つき絵本）も表紙まで確認。

## PR #1（絵の中を探索する動く絵本）を遊んだ流れ

1. 導入：スノードームの中のサンタ＋雪の森。絵は一目で「絵本だ」と分かる品質。深い青と金色、雪の質感、温かい光。大人が「きれい」と言うレベル。
2. 台詞は文字のみ。音声なし。「まほう使いにいたずらされて、この端末に閉じ込められてしまったのじゃ」— 絵はスノードームなのに文は「端末」。原作（スマートスピーカー）由来の言葉が残り、絵と矛盾。
3. 漢字が多い（端末・閉じ込め・必要・隠れた・調べる・脱出）。ふりがな無し。5〜6歳は一人で読めない → 大人が読み上げる前提だが、そのための設計（読み聞かせモード、ふりがな、台詞の切り方）は無い。
4. 三つの箱：森の絵に赤・青・黄の箱。箱の下に「調べる」ボタン。「ひみつの言葉を伝える」は常に表示（原作の直行経路）。
5. 赤い箱：ページ遷移（毎回1〜3秒「雪の森を読み込んでいます…」の暗転）→「箱を大きく見る」でモーダル → 「調べてみる」ボタンを3回押すと雪が段階的に消え「サンタ、イタチ／サンタ、ハタチ」＋たぬきの絵＋「×ぬき」が現れる。雪払いは指でこする操作ではなくボタン。押下中は「調べています…」でロック。
   - 謎：タを抜く → サン・イチ・サン・ハチ → 3138。7〜8歳＋大人のヒントでちょうど良い「アハ体験」。大人もクスッとできる。
   - 四桁錠：見た目は真鍮のダイヤルで魅力的。ただし上下ボタンが小さく、向き（「下へ回す」で数字が減る）が直感と逆に感じた。ダイヤルをクリックして数字キー入力を試したが反映されなかった（フォーカスの当て方が分かりにくい）。
   - 解錠：「カチッ。鍵が開いた。」→ ふたを上にドラッグ → 「す」「だ」の紙。ここの物理的な手応えは良い。サンタは球内で喜ぶ（小さな反応）。
   - 画面下に開発者向けの操作説明（「上下に引く · ↑↓で回す · 数字キーで入力」「↑ ↓ で調整 · Home / End」）、「少し閉じる／少し開ける」スライダー、「森に戻る／青い箱へ／黄色い箱へ／六枚の紙のひみつへ」の小リンク群。子どもには不要な情報が多い。
6. 青い箱：山の絵→「サガルマータ」→「その高さは、この端末が知っている」。「サガルマータについて調べる」ボタンで固定資料。原作はスマートスピーカーに聞く仕掛けだった。ブラウザでは「資料を読む」になり魔法が消えている。答え8848は推論ではなく知識。子どもには解けないが、大人が「エベレストだよ！」と言える＝大人の出番になり得る。
7. 六枚の紙：パネルUIで紙をタップ→枠をタップで並べる。「だいすきだよ」を自分の手で並べる瞬間は物語の頂点なのに、機能的なパネルと「この並びで伝える」ボタンで終わり、成功表示は短く自動遷移。声に出して言う儀式が無い。
8. 発見：枝をドラッグ／ボタンで開くと、奥から光と「まほう使い」（かわいい少女の魔女）が現れる。演出は美しい。「こんどは、わたしと遊んで。」
9. まほう使いと三問：別ページ。台詞パネル＋入力。
   - なぞなぞ「クリスマスの中の生き物」→ 自由入力（かな）。タブレットで子どもがかな入力するのは難しい。
   - 三択「ツリーの赤い玉」→ ボタン。わざと誤答しても優しく正解を教えて進む（原作どおり）。
   - 「シカ、シカ…と10回いってね」→ 文字だけ「シカ、シカ...」。声に出してこそ成立するひっかけが、文字では成立しない。親子で一緒に声に出すと最高に盛り上がるはずの場面。
10. 救出：金色の光を右へ引くと球がほどけ、サンタが等身大で外に出てくる。感情的な山場として機能。本文：「まほう使いめ。かまってやらなかったからって、とじこめることはないじゃろう」「だって、だって、さびしかったんだもの。けど、今日はきみと遊べて、とっても楽しかったよ！」「クリスマスの夜を楽しみにしていてくれ」。
    - テーマ：まほう使いは「かまってもらえなかった」から寂しかった → 遊んでもらえて満たされた。大人にとっては「一緒に遊ぶこと」の物語として刺さる二重の意味。
    - 結末の「クリスマスの夜を楽しみにしていてくれ」は、現実のクリスマスイブ／25日朝のプレゼントへ物語を橋渡しできる最大のフック。
11. 所要時間：答えを知っている大人の通しで約10分。初見の親子なら30〜45分程度と推定（箱ごとに5〜10分）。

## main の prototype/（声つき絵本）

- 表紙は紙工作風のフラットなSVG/CSSイラスト（スマホの中のサンタ）。見開き絵本レイアウト。声（Gemini TTS: サンタ Algieba、語り Sulafat、妖精 Leda）とBGM・効果音つき。聞き直す／停止／音声オン／BGMスライダー。
- PR #1 の絵とは画風が全く違う（二つのアートディレクションが併存）。声の資産は PR #1 には接続されていない。

## 総括（体験面の第一印象）

- 強み：絵の美しさ、物理的な錠と箱の手触り、だいすきだよ→魔女→救出という感情の流れ、原作の謎の質（タヌキ算・負けるが勝ち）。
- 弱点：音が無い（PR）、読字前提の漢字テキスト、毎シーン暗転するページ遷移、開発者向けUIの露出、子どもが主役になれる手の操作が少ない（ボタン中心）、大人の役割が設計されていない（読む・ヒントを出す・知識を出す・一緒に声を出す、が全部偶然任せ）、クライマックス（だいすきだよ・シカ10回・救出後）の儀式化不足、現実のクリスマスへの橋渡しが無い。
