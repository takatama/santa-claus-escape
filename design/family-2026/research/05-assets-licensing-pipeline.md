## 0. 結論（先に要点）

1. **素材は大きく三系統。権利の状態はそれぞれ違う。**【確認】
   - (a) **生成イラスト**：PNG 21枚、45.5MB。PR #1 の `illustrated-prototype/` にある。**全21枚の C2PA に `ChatGPT` / `gpt-image` / `trainedAlgorithmicMedia` の記録があり、OpenAI の画像モデルで作られた**。ただし **`NOTICE.md`（2026-10-06更新）はこれらの画像に触れていない**。PR #1 は `NOTICE.md` を変更していない。
   - (b) **Gemini TTS の声**：WAV 81本、約17.5分、約51MB。うち本編で使うのは68本・約13.9分。NOTICE 上は MIT。
   - (c) **原作から復元した第三者音源**：BGM 2曲（PeriTune、CC BY 4.0）、効果音6点（CC0 1点＋効果音ラボ4点＋効果音辞典1点）。**結末の鈴（DOVA/OpenTracks）は保留中で同梱していない**。

   - キャラクター表情差分の一致
   - 透明部の縁ゴミの処理
   - 縦長スマホ向けの構図
3. **画風を決めた参照画像3枚（`design/visual-directions/2026-10-07/artistic-page-reveal/`）がリポジトリに無い**。【確認】このままでは再現性が切れる。出所（自作か、生成か、第三者作品か）も記録が無い。【要確認】

6. **配布形態でライセンスの重さが変わる。**
   - **無料の Web 版**：現状の記録とゲーム内クレジット（`prototype/full-app.js:101`）でほぼ足りる。
   - **ストア配信（特に有料・Kids）**：次の対応が要る。【推測／一部確認】
     - 第三者音源を簡単に取り出せないようにする（PeriTune の新規約・効果音ラボ FAQ の推奨・OpenTracks の禁止事項）
     - Kids カテゴリでは、外部リンクの前に保護者ゲートを置く

## 2. 画像生成パイプライン

### 2.1 ツールとモデル

- **【確認】** すべての PNG に `caBX` チャンク（C2PA マニフェスト、21〜24KB）がある。中身は次のとおり。
  - `softwareAgent` = `ChatGPT`、`version` = `gpt-image`
  - `digitalSourceType` = `trainedAlgorithmicMedia`
  - 署名は `OpenAI OpCo, LLC`
  - `c2pa.watermarked.unbound` アサーションがある
- **【確認】** 記録上のツール名は「built-in image_gen / image_gen.imagegen」（各 `PROMPTS.json`）。生成先は `（作成者のローカルパス）`。
  - Codex CLI の組み込み画像生成で作ったことになる。
  - セッションIDは `01a114e0…` と `01a11851…` の2つ。
- **【推測】** モデルの正確な版（gpt-image-1 系の世代）は C2PA にも記録が無い。将来の追加生成では、モデル更新によって画風がずれる可能性がある。

### 2.2 プロンプトの型【確認】

すべて英語で、次の型に揃っている。
- `Use case: illustration-story | precise-object-edit | background-extraction / identity-preserve`
- `Asset type: …`
- 入力画像の役割宣言（"STYLE REFERENCES ONLY" / "exact EDIT TARGET"）
- 画材の指定：tactile gouache / watercolor on fibrous paper、midnight-blue、antique gold
- 構図と余白：generous transparent margin、readable at 45–90px
- 長い否定リスト：NO book, NO text, NO digits, NO UI…

謎の答えを絵に出さないための否定（例：`must not embed the puzzle answer or the word Sagarmatha`、`never display the solution`）が徹底されている。全文は以下にある。
- `illustrated-prototype/assets/PROMPTS.json`
- `assets/FOREST-EDIT.md`、`assets/WIZARD-FEET-EDIT.md`
- `{red,blue,yellow}-box/assets/PROMPTS.json`、`rescue/assets/PROMPTS.json`
- `red-box/concepts/2026-10-08/PROMPTS.md`、`LOCK-MOUNT-EDIT.md`

### 2.3 一貫性を保つ方法【確認】

1. **画風の参照画像3枚**：`design/visual-directions/2026-10-07/artistic-page-reveal/01〜03.png`。初期4素材すべての入力。**リポジトリに無い**（`ls` で不在。git 履歴にも無い。`storyboard/PLAN.md:118` に「配布対象外」と書かれている）。
2. **兄弟編集**：赤い本体を青に色替え編集し、さらに黄に色替え（`yellow-box/assets/PROMPTS.json` に `reference_images` = blue-body の絶対パス）。形が揃い、成功している。
3. **同一性を保つ編集**：
   - `globe.png` → 中身を消して `empty-globe.png`
   - `globe.png` → サンタだけ抜き出して `santa.png`
   - `wizard.png` → 脚だけ直して `wizard-feet-v2.png`
4. **ランタイム側の工夫**：
   - 絵は「背景1枚＋透明スプライト」で構成し、Canvas 2D で合成する。透明部の余白はメモリ上で切り詰める（`rescue/paint.js`）。
   - 錠・文字・紙・雪はコードで描き、生成絵に謎の情報を焼き込まない。**大量生産しやすい良い設計**。
5. **記録**：採用・不採用、生成元のパス、目視確認の内容を Markdown/JSON に残している。ただし形式がファイルごとに違う（`assets` は `prompt` だけ、`rescue` は Codex のヒント文をそのまま保存、など）。

### 3.4 Gemini API 規約の年齢条項（重要）【確認＋要確認】

[Gemini API Additional Terms](https://ai.google.dev/gemini-api/terms)（WebFetch の要約で取得、Last Modified 2026-03-23）には次の趣旨の条項がある。
- 18歳以上であること
- 18歳未満を対象とする、または18歳未満が利用しそうな Web サイトやアプリの一部として本サービスを使わないこと

さらに、
- 無料枠では、入力と生成物が Google の製品改善に使われる
- 有料枠では使われない
- 生成物の所有権を Google は主張しない。ただし同じか類似の生成物を他者にも出しうる

今回は**実行時に API を呼ばない（事前生成した WAV を同梱）**。それでも、子ども向けとして宣伝する製品にこの声を載せることが「サービスの一部として使う」に当たるかは、規約の文面からは判断できない。**ストア配信、とくに Kids カテゴリやファミリー向けの訴求をする前に、Google への照会か法務確認が必要**。

代替案：
- 人の声優
- 子ども向け用途を明示的に許す TTS
- 「保護者が読み聞かせ、キャラクターの声だけ録音を使う」構成

いずれも Gemini 依存を減らせる。

1. **NOTICE に画像が無い**【確認】

2. **AI 生成画像が著作物になるかは不確実**【推測】
   - 日本では、文化庁「AIと著作権に関する考え方について」（2024年）で、人の創作的な寄与があれば著作物になりうると整理されている。プロンプトだけでは弱い。
   - MIT 表示をしても第三者の流用を止められない可能性がある。
   - **ブランド保護は、タイトル・ロゴ・キャラクター名の商標や、人手で仕上げたキービジュアルで担保する方が確実**。
3. **参照画像3枚の出所が不明**【要確認】
   - 初期4素材はすべてこの3枚を「人物と画風の参照」にしている。
   - 参照画像が第三者の作品なら、派生とみなされるリスクがある。
   - 出所（自作、生成、購入）を記録し、非公開のまま保管する。
4. **ローカルパスと作業メモの露出**【確認】
   - 次の記述が公開リポジトリに入っている。
     - `（作成者のローカルパス）`（`illustrated-prototype/README.md:40`、`storyboard/PLAN.md:98`、各 `PROMPTS.json`、`HANDOFF.md:9`）
