# 台詞と効果音の順序修正

2026-10-06。利用者から、救出・三箱の効果音が台詞より前に鳴ること、数字を合わせる音の欠落、開箱後のサンタの説明の繰り返しを指摘されたため修正。

## 原作との照合と現在の順序

参照コピー `prototype/reference/legacy-index.js` の `redSolved`・`blueSolved`・`yellowSolved`・`notSolved*`・`finalSmartPhone` のSSMLで挿入位置を確認。原本は変更していない。

- 正解：ダイヤル音 → 1秒 → 数字の確認 → 0.5秒 → 解錠音 → 箱が開いた台詞 → 正解音 → 紙の説明。
- 不正解：ダイヤル音 → 1秒 → 数字の確認 → 1秒 → 開かなかった台詞 → 不正解音。
- 救出：「うふふ。ああ楽しかった！」→ 0.5秒 → 救出の効果音 → 登場の案内 → 0.5秒 → サンタから始まる会話 → 最後の案内。
- 妖精の登場：登場音 → 妖精とナレーターの会話。

原作の箱の数字はsay-as charactersなので、既存の数字0〜9と三色の前置き、共通の「に合わせました。」を再利用する。紙の説明・開いた宣言・救出の最初の二台詞だけを分けて収録。救出の長い会話と最後の案内は、既存のC2PA付き原音をバイト一致で再利用。

以前は場面の開始時に効果音を鳴らしていた。現在は `timed-audio.js` で発話区間と効果音の順番を指定し、`audio-timeline.js` で声用と効果音用のバッファを同じ時計で開始する。実際にデコードした各区間の長さから位置を決め、推測した秒数に効果音を予約しない。声の終わりや効果音の長さで、後の台詞の位置も決まる。

音量は声1、効果音0.18、不正解0.10、自作のダイヤル0.12・解錠0.14。再生中の「効果音オフ」は効果音のゲインだけを0にし、声を続ける。停止・ミュート・画面切替では両方を止め、未再生の音も破棄する。効果音だけ取得できない場合は声を続け、声の取得や再生に失敗した場合は同じ場面のブラウザ読み上げへ戻す。

## ダイヤルと解錠音

原作には `dial.mp3` の指定がある。参照はFreesoundのdial-turningタグ一覧で、固有ID・作者・ライセンスの特定は未完了。そのため原音を公開配信しない。以前の自作の短い三角波を、乾いた機械クリックの自作音へ変更し、ダイヤルの各タップで一音、回答確定時に「カチカチ、カチカチ」の四音を再生する。

解錠の「カチャ」も自作。原作の `unlocking-1.mp3` は今回採用していない。この二つの自作音はコードで生成し、MITの対象。効果音ラボの正解・不正解・登場・救出の四音は従来の公式MP3を再利用し、提供元の規約が適用される。終盤のジングルも今回の修正では追加していない。

## 開箱後の案内

初回の三箱の説明は原作のサンタの台詞を維持。箱を一つ以上開けて箱選択へ戻る場合は、利用者の指定により「残りは青色と黄色の箱です」のように未開封の箱だけをナレーターが伝える。六通りの残りの組み合わせを固定データと音声にした。これは原作台詞の変更として記録し、謎・正解・自由順・救出条件は変更しない。

残りの箱が変わった案内も、進行履歴へ別の場面として記録する。再開・読み返しでは、その時点の未開封の箱を示す。保存形式のバージョンは変えず、旧履歴も読み込める。
